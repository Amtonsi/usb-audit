Журнал USB

USB-Audit v1.1.0 для Windows x64. Установка на автоматизированном рабочем месте (АРМ), история подключений съёмных носителей информации (СНИ), файловые операции и обслуживание архивов.

Автор — Амаль А. (Amtonsi) · Лицензия MIT

Алгоритм работы

Прокрутите схему по горизонтали, чтобы увидеть обе ветви.

Первый запуск

На АРМ понадобятся Windows 10 или 11 x64, штатная Windows PowerShell 5.1, Планировщик заданий и том NTFS для журнала. Просмотр работает в современном браузере с включённым JavaScript.

До первой установки в повышенной Windows PowerShell сохраните вывод следующих команд отдельно от папок программы. Для восстановления настроек понадобятся исходные режимы всех четырёх подкатегорий аудита. Для «Файловой системы» и «Управления дескрипторами» (Handle Manipulation) запишите оба флага — успех и отказ. Также сохраните разрешения журнала «Безопасность», тип и значение HotPlugSecureOpen либо его отсутствие, а также наличие источника событий программы.

auditpol.exe /get '/subcategory:{0CCE9245-69AE-11D9-BED3-505054503030}'
auditpol.exe /get '/subcategory:{0CCE9248-69AE-11D9-BED3-505054503030}'
auditpol.exe /get '/subcategory:{0CCE921D-69AE-11D9-BED3-505054503030}'
auditpol.exe /get '/subcategory:{0CCE9223-69AE-11D9-BED3-505054503030}'
(Get-WinEvent -ListLog Security -Force).SecurityDescriptor
reg.exe query 'HKLM\SYSTEM\CurrentControlSet\Control\Storage' /v HotPlugSecureOpen
[Diagnostics.EventLog]::SourceExists('LocalUsbAuditMaintenance')
  1. На рабочем АРМ администратор копирует USB-Audit.exe в локальную папку, где операторам разрешены чтение и запуск, а запись разрешена администраторам. Это особенно важно, когда администратор подтверждает UAC в сеансе другого пользователя. Выполните в этой папке команду PowerShell, приведённую ниже, и сравните SHA-256 файла с опубликованным значением для этой версии.
  2. Войдите под учётной записью сотрудника, которому нужен отчёт, и дважды щёлкните USB-Audit.exe. В окне «Журнал USB» нажмите «Установить». Подтвердите запрос UAC или введите учётные данные администратора. Программа назначит права чтения пользователю, открывшему окно.
  3. В окне «Ответственный за архивы» раскройте список и выберите существующую учётную запись администратора этого компьютера. Под списком появится SID — идентификатор выбранной учётной записи Windows. Сверьте имя и SID и перед подтверждением проверьте папки назначения. Сборщик работает от имени службы. Оператор получает права чтения, а выбранный администратор подтверждает закрытие журнала и удаление архива.
  4. Дождитесь результата установки. После первого добавления в группу чтения выйдите из сеанса Windows и войдите снова, чтобы обновились права пользователя. Откройте EXE, нажмите «Проверить», подключите контрольную флешку и выполните проверку регистрации.

Установщик помещает рабочие файлы на АРМ, включает успешный аудит Plug and Play и съёмных носителей и создаёт задания LocalUsbAuditCollector и LocalUsbAuditMaintenance. После того как сборщик подтвердит чтение журнала «Безопасность» и запись в собственный журнал, установщик задаёт HotPlugSecureOpen=1 и дважды проверяет, сохранилось ли значение. Если Windows сбрасывает его, установщик повторяет настройку. После трёх неудачных попыток выводится ошибка.

Сборщик запускается от службы LOCAL SERVICE при загрузке Windows и продолжает работать после выхода пользователя. Для просмотра и экспорта отчёта установщик создаёт локальную группу LocalUsbAuditReaders и добавляет в неё выбранного читателя.

Какие папки контролировать

При первом запуске установщик предлагает папку «Общие документы\USB-Audit-Inbox». Нажмите «Добавить папку…», чтобы указать дополнительные папки, куда сотрудник обычно копирует файлы с флешки. Команда [Environment]::GetFolderPath('CommonDocuments') показывает расположение «Общих документов» на этом АРМ. Стандартную подпапку USB-Audit-Inbox программа может создать. Остальные папки должны существовать на локальном несъёмном томе NTFS. Для вложенных папок укажите только родительскую. Для документов используйте папки вне системных каталогов, корней томов и ссылок на другие папки.

Установщик включает успешный и неуспешный аудит файловой системы Windows. Для регистрации отказов в доступе к архиву он также включает аудит отказов в «Управлении дескрипторами» (Handle Manipulation). Действующее значение флага успеха в этой подкатегории сохраняется. Для выбранных папок он задаёт правила аудита (SACL) записи файлов, для архива — успешных и отклонённых обращений, связанных с изменением или удалением. Правило папки назначения обычно наследуют вложенные папки и файлы. Если на объекте отключено наследование SACL и нет собственного правила аудита записи, либо для этой операции действует исключение политики аудита Windows, событие 4663 для назначения может отсутствовать. Дополнительно сборщик следит за созданием и переименованием файлов в наблюдаемых папках. При единственном подходящем чтении с носителя результат зависит от того, удалось ли сравнить содержимое.

Чтобы обновить установленный сборщик, откройте новый EXE, выберите «Обновить» и подтвердите UAC. Новые папки добавятся к сохранённым. Прежние журналы доступны в отчёте. Сведения о месте назначения и действиях с архивами появляются для операций, наблюдаемых после настройки соответствующего аудита.

Кого можно назначить

В списке отображаются включённые пользователи этого компьютера, которые непосредственно входят в его группу «Администраторы». УЗ для подтверждения UAC и УЗ ответственного могут различаться. При первой установке нажмите имя в списке даже при единственном варианте. «Отмена» закрывает окно до установки.

При назначении ответственного достаточно выбрать его УЗ. Для закрытия журнала и удаления архива понадобится пароль Windows этой УЗ. Для просмотра и копирования отчёта достаточно прав читателя.

Как сменить ответственного

Нажмите «Проверить». Строка «Ответственный за архивы» показывает назначенное имя, SID и результат проверки действующего членства в группе администраторов. Для смены ответственного нажмите «Обновить», подтвердите UAC и выберите другую УЗ. При обычном обновлении программа выделяет действующего ответственного, если его SID по-прежнему доступен. После смены архивы остаются в истории. Следующая операция через программу потребует пароль нового ответственного.

Если ответственного отключили, удалили или исключили из группы администраторов, откройте «Обновить» и назначьте действующую УЗ. Учётная запись, заново созданная с прежним именем, получает другой SID и также требует явного выбора. При пустом списке нажмите «Отмена» и проверьте у администратора АРМ наличие включённого пользователя с прямым членством в локальной группе «Администраторы».

Установка из командной строки

Для установки без окна выбора нужны два SID. В сеансе сотрудника, которому нужен отчёт, команда whoami.exe /user покажет SID читателя. Откройте 64-разрядную Windows PowerShell от имени администратора в папке с EXE. Команда --list-admins перечислит имена и SID ответственных. Передайте --install сначала SID читателя, затем SID ответственного. Для каждой папки укажите --watch-folder и её полный путь. При первой установке с этим параметром используются указанные пути. Если его пропустить, при первой установке выбирается стандартная папка, а при обновлении сохраняются настроенные папки.

$previousEncoding = [Console]::OutputEncoding
try {
    [Console]::OutputEncoding = [Text.UTF8Encoding]::new($false)
    .\USB-Audit.exe --list-admins | Out-Host
    if ($LASTEXITCODE -ne 0) { throw 'Список администраторов недоступен.' }
    $readerSid = Read-Host 'SID сотрудника из вывода whoami /user'
    $adminSid = Read-Host 'SID ответственного из вывода --list-admins'
    $folder = Read-Host 'Полный путь к существующей папке назначения на локальном NTFS'
    .\USB-Audit.exe --install $readerSid $adminSid --watch-folder "$folder" | Out-Host
    $result = $LASTEXITCODE
} finally {
    [Console]::OutputEncoding = $previousEncoding
}
$result

Код 0 означает успех. При ошибке установки EXE возвращает 1 и выводит её причину. С одним SID читателя команда --install открывает окно выбора ответственного. При отмене выбора возвращается код 3.

Как читать историю

  1. Откройте USB-Audit.exe и нажмите «Открыть журнал». В таблице «Носители» видны модель, полный идентификатор экземпляра устройства, аппаратный серийный номер и количество сеансов. Если накопитель не сообщает номер, появится отметка «Не предоставлен устройством».
  2. Нажмите строку носителя. В «Истории подключений» выберите нужный сеанс по времени начала и букве диска. Один и тот же носитель может получить разные буквы при разных подключениях.
  3. В таблице «Файловые операции» по умолчанию видны «Изменения файлов». Найдите имя файла, проверьте его путь, действие, учётную запись и процесс. Чтобы посмотреть отдельные события Windows, в панели фильтров рядом с поиском выберите «Все обращения».

Как увидеть перенос со СНИ на компьютер

В выбранном сеансе найдите таблицу «С носителя на компьютер». В ней видны время, файл на носителе, полный путь назначения, учётная запись и процесс. Введите в поиск имя файла или часть пути назначения. Например, при копировании E:\Документы\План.txt в стандартную папку в одной строке появятся путь с флешки и путь из USB-Audit-Inbox.

«Содержимое совпало» означает, что при проверке оба файла дали одну и ту же SHA-256. Нажмите «SHA-256» в таблице, чтобы увидеть сумму. Под результатом указан источник сведений о месте назначения.

  • «Чтение и запись в журнале Windows». События 4663 связывают чтение с флешки и запись в выбранную папку. Процесс, учётная запись и сеанс входа совпали.
  • «Уведомление папки назначения». Сборщик получил уведомление о создании или переименовании файла, нашёл единственный подходящий источник с тем же именем и сверил содержимое. В графе «Учётная запись и процесс» указан тот, кто читал СНИ. Автор и процесс записи из уведомления неизвестны. При перезаписи существующего файла уведомления об обычном изменении недостаточно. Этот способ требует доступа сборщика к папке и обоим файлам, а также доступной флешки во время проверки. Во время проверки сравниваются доступные файлы на обеих сторонах.

«Вероятный перенос» возможен при паре событий 4663. Между чтением и записью не более восьми секунд. У обращений совпали имя файла, процесс, учётная запись и сеанс входа. Найден один подходящий путь на СНИ. Проверка содержимого оказалась недоступна. При подтверждённом различии файлов или неоднозначной связи строка переноса не создаётся.

«Возможный перенос · появился одноимённый файл». Папка назначения сообщила о создании или переименовании файла с тем же именем, а в пределах восьми секунд было единственное подходящее чтение с СНИ. Сборщик даёт аудиту Windows ещё 16 секунд, чтобы предпочесть запись с известным процессом. Подтвердить содержимое не удалось, например из-за размера файла или занятости носителя. Если доступны размеры, отчёт показывает их на момент проверки. Разная длина может означать, что файл ещё записывался. При одинаковой длине и разных проверенных SHA-256 пара исключается. Завершение копирования и автор записи по этим признакам неизвестны. Перезапись существующего одноимённого файла может попасть в таблицу при наличии пары событий 4663. Одни фоновые уведомления об изменении (Changed) основания для переноса не дают. Если найдено несколько подходящих источников, либо программа установила различие содержимого, строка переноса не создаётся.

Сравнение содержимого рассчитано на доступные непустые файлы до 4 МиБ включительно. Занятость сборщика, блокировка или извлечение флешки могут ограничить проверку. Для пути вне наблюдаемых папок, другого имени назначения или единственного чтения смотрите «Все обращения». По одному чтению нельзя определить путь копии. Даже при совпадении содержимого данные не показывают, выбрал пользователь копирование или перемещение.

Как выглядит копирование одного файла на носитель

Допустим, вы скопировали через Проводник файл План.txt. За одну секунду Windows зарегистрировала чтение корня тома и два обращения к файлу — запись и добавление данных. В «Изменениях файлов» появится одна строка «Запись данных» для План.txt с числом обращений 2. В режиме «Все обращения» видны обе записи по файлу и обращения к корню тома.

Сводка объединяет события одного вида по одному пути, от одной учётной записи и одного процесса в одном сеансе. В такую строку попадают обращения в пределах двух секунд от первого и одной календарной даты. В графе «Время» указано время последнего обращения группы. Отдельная строка «Использование права удаления» возможна, например, при удалении или переименовании. Установить исходный путь копирования по записи на носитель нельзя.

Поиск по файлу учитывает выбранный режим. В сводке счётчик показывает число сгруппированных изменений, в полном режиме — число отдельных обращений. Для проверки чтения переключитесь на «Все обращения» и введите имя файла в поиск. Windows может показать путь к нему через имя тома, например \Device\HarddiskVolume3\План.txt.

При большом числе подключений таблицы разбиты на страницы. На странице помещается до 15 носителей, 15 сеансов выбранного носителя или 40 строк в разделе «Файловые операции». Для переносов и действий с архивами предусмотрено по 20 строк на страницу. Используйте поиск по идентификатору, номеру, файлу или учётной записи и ограничивайте период с помощью полей дат. Время приведено в часовом поясе компьютера, на котором открыт HTML.

Для просмотра накопленной истории запустите актуальный USB-Audit.exe под учётной записью читателя и нажмите «Открыть журнал». Программа применит встроенный шаблон к текущему журналу и доступным архивам. Для одного архивного файла выберите «Архивы…» → «Открыть архив». Эти действия доступны с правами читателя без переустановки сборщика.

Открытый HTML показывает данные на момент формирования. Чтобы увидеть новые события, снова нажмите «Открыть журнал». Кнопка «Сохранить копию отчёта» сохраняет весь снимок, включая обращения, скрытые выбранным режимом и фильтрами. Ранее сохранённые HTML-копии сохраняют свой исходный вид.

Как понимать записи

В истории строка «Открыт» означает, что в журнале есть начало сеанса и сборщик ещё не зарегистрировал его завершение. Если при запуске сборщика флешка уже подключена, за начало сеанса принимается время первого обнаружения.

После извлечения флешки сборщик закрывает сеанс. Если Windows передала уведомление об удалении тома, в истории указано время этого события. При безопасном извлечении оно может предшествовать физическому отключению флешки. Без уведомления сборщик ждёт двух успешных опросов подряд, в которых диск отсутствует. В обоих случаях состояние сеанса — «Извлечён». Пометка «Обнаружено при опросе» в графе «Извлечение» показывает, что отключение произошло между последним обнаружением диска и первой проверкой, когда он уже отсутствовал.

Если для прежнего сеанса записано только последнее наблюдение, программа при формировании отчёта ищет подходящее событие Windows для этого устройства. При подтверждении в истории появятся «Извлечён» и пометка «Событие Windows 1010». При перерыве в наблюдении или отсутствии подтверждения состояние остаётся «Не определено». Если конец сеанса отсутствует в выбранном архиве, нажмите «Открыть журнал», чтобы проверить все доступные записи.

Проверка извлечения по двум опросам действует сразу после установки этой версии. Если на АРМ уже работает другая сборка, запустите EXE этого выпуска, нажмите «Обновить», подтвердите запрос Windows и выбор ответственного. Затем сформируйте отчёт кнопкой «Открыть журнал».

Чтение может выполнять пользовательская программа, антивирус или иной фоновый процесс. Одна запись о чтении не устанавливает, куда скопировали данные. Программа рассчитана на USB-устройства, которые Windows распознаёт как дисковые накопители.

Проверка на контрольной флешке

Проверяйте учёт операций по уникальному имени файла. Корень диска и события распознавания устройства сами по себе не подтверждают чтение или запись конкретного файла.

  1. Нажмите «Проверить». Убедитесь, что задача сборщика работает, а аудит успешных операций со съёмными носителями включён. Для чтения всех системных параметров может понадобиться запуск EXE от имени администратора.
  2. Подключите разрешённую тестовую флешку после включения аудита. В Проводнике выберите её раздел данных и запишите в отдельный тестовый файл несколько строк. Задайте новое имя, например Проверка-СНИ-01.txt. Закройте файл, заново откройте его для чтения и закройте.
  3. Через несколько секунд нажмите «Открыть журнал». Проверьте идентификатор и серийный номер носителя, если он доступен, и выберите тестовый сеанс. Введите имя контрольного файла в поиск. В «Изменениях файлов» проверьте запись. В режиме «Все обращения» проверьте чтение, учётную запись и процесс. Удалите созданный вами контрольный файл.
  4. Безопасно извлеките флешку, отключите её и дождитесь исчезновения диска в Windows. Оставьте её отключённой на время двух опросов, обычно около 10 секунд. Снова нажмите «Открыть журнал» и проверьте состояние «Извлечён» у тестового сеанса. Подключите флешку ещё раз и убедитесь, что в истории появилась отдельная строка. Повторите операции с файлом под другим именем.

Для автоматической сверки выполните в 64-разрядной Windows PowerShell следующую команду с фактическим именем контрольного файла. Сценарий ищет среди последних 2000 строк активного журнала события за 15 минут. Подтверждение означает, что Windows зарегистрировала и чтение, и запись по одному пути в одном сеансе.

& "$env:ProgramFiles\LocalUsbAudit\Check.ps1" -TestFileName 'Проверка-СНИ-01.txt'

Контроль переноса с носителя

  1. Создайте на тестовой флешке два небольших непустых документа с разными уникальными именами. Скопируйте первый в выбранную при установке папку и сохраните имя. Второй откройте только для чтения. Дождитесь окончания копирования, закройте файлы и оставьте носитель подключённым ещё примерно на 25–30 секунд, чтобы сборщик сопоставил события и при необходимости сравнил содержимое.
  2. Нажмите «Открыть журнал». В соответствующем сеансе проверьте первую строку по двум путям и основанию. Для второго файла проверьте чтение в режиме «Все обращения». Одного чтения для строки переноса недостаточно. Если назначение первого файла отсутствует, сверьте выбранную папку и «Состояние сбора». Проверьте событие 4663 для чтения с СНИ. При отсутствии 4663 для назначения повторите тест с новым именем в доступной сборщику папке и оставьте флешку подключённой для сверки SHA-256.

Виден носитель, но не виден файл

Переключитесь на «Все обращения» и проверьте период поиска. Если файл по-прежнему отсутствует, в «Просмотре событий» откройте «Журналы Windows» → «Безопасность» и найдите событие 4663 категории «Съёмные носители» за время проверки. Посмотрите поле имени объекта. Если события с контрольным именем есть, сформируйте отчёт заново и проверьте «Состояние сбора» и принадлежность файла нужному тому и сеансу.

На некоторых сборках Windows для файлового аудита нужен параметр HotPlugSecureOpen типа DWORD со значением 1. Узнать фактическое значение можно в PowerShell.

Get-ItemPropertyValue -LiteralPath 'HKLM:\SYSTEM\CurrentControlSet\Control\Storage' -Name HotPlugSecureOpen

При значении 0 или отсутствии параметра администратору следует проверить действующие политики АРМ. Кнопка «Обновить» повторно применяет настройки установки. После применения настройки снова физически переподключите флешку, проверьте значение и повторите контрольную операцию. Документация Microsoft по аудиту съёмных носителей.

Архивы и права доступа

Сборщик получает право добавлять строки в активный журнал. Участники группы LocalUsbAuditReaders могут читать и копировать данные. Назначение прав охватывает сам файл и его родительскую папку. Задание LocalUsbAuditMaintenance выполняет подтверждённую операцию с архивом от имени SYSTEM. Локальный администратор Windows сохраняет возможность изменить владельца и разрешения NTFS.

Почему Windows может запросить подтверждение дважды. UAC разрешает запуск установленного сценария с правами администратора. В сеансе обычного оператора Windows может запросить для этого учётные данные администратора АРМ. Затем сам сценарий проверяет пароль конкретной УЗ, назначенной ответственной за архивы. Этот второй шаг выполняется и при запуске из уже повышенного сеанса.

  1. Нажмите «Архивы…». Выберите закрытый файл и нажмите «Открыть архив», чтобы сформировать отчёт только за этот файл. Для просмотра и копирования достаточно прав читателя. Если сеанс пришёлся на границу архивов, откройте полный журнал для просмотра всей доступной истории.
  2. Чтобы закрыть текущий журнал, нажмите «Закрыть текущий журнал». Программа сверит установленные сценарии с версией открытого EXE и вызовет системную Windows PowerShell с повышенными правами. Подтвердите UAC, если Windows показывает запрос. В отдельном окне PowerShell сверьте указанную УЗ, введите пароль ответственного и нажмите Enter. После успеха журнал перейдёт в архив, сбор продолжится в новом файле.
  3. Чтобы удалить архив, выберите закрытый файл и нажмите «Удалить архив». Сверьте имя файла и подтвердите удаление. После повышения прав введите пароль назначенного администратора в окне PowerShell. Этот шаг повторяется при каждом закрытии журнала и удалении архива, в том числе в сеансе самого ответственного. Windows проверяет пароль, затем сценарий сверяет SID вошедшего пользователя с SID ответственного. При ошибке прочтите причину в окне PowerShell и нажмите Enter, чтобы закрыть его.
  4. Для дополнительной проверки обслуживания откройте журнал Windows «Приложение» и выберите источник LocalUsbAuditMaintenance. События 100 и 101 соответствуют запросу и завершению закрытия, 110 и 111 — запросу и завершению удаления. Событие 119 содержит ошибку.

Сразу после закрытия журнала новый активный файл может занимать 0 байт. «Проверить» покажет, что файл доступен и пока пуст. Для проверки поступления новых записей подключите СНИ и сформируйте отчёт повторно.

Если UAC отменён при удалении, операция завершается до запроса пароля, а интерфейс передаёт событие отмены в журнал «Приложение». При неверном пароле архив сохраняется. Введённый пароль обрабатывают повышенный сценарий и Windows. Журнал и конфигурация содержат служебные данные без пароля. Если программа сообщает о несовпадении контрольной суммы сценария, откройте EXE установленной версии и сверьте его SHA-256.

Удаление архива относится к выбранному файлу. Ранее сохранённые копии отчётов и штатные события Windows имеют собственные сроки хранения. При большой истории контролируйте свободное место и периодически закрывайте журналы.

Попытки изменить и удалить архив

Откройте общий журнал и перейдите к таблице «Действия с архивами». Она доступна и без подключённой флешки. Здесь можно искать по пути архива, учётной записи, действию, результату или процессу. Действия после закрытия архива попадают в текущий журнал и последующие архивы. Отдельно открытый архив содержит записи своего периода.

Источник «Windows Security» означает прямое обращение программы к файлу или каталогу архивов. Для появления события 4656 при отказе должны действовать правило SACL архива и политика аудита отказов «Управление дескрипторами». Событие 4656 показывает запрос и решение о доступе, 4663 — использование права. Право удаления используется также при переименовании. Источник «Интерфейс USB-Audit» фиксирует выбор удаления и отмену подтверждения или UAC. Источник «USB-Audit» показывает этапы обслуживания, включая отказ в авторизации и результат выполнения. Введённый пароль в отчёт не попадает.

Для проверки возьмите расходный тестовый архив. В сеансе обычного читателя запросите открытие этого файла на запись. Команда ниже открывает и закрывает существующий файл без изменения содержимого. Проверьте в общем журнале путь, время, учётную запись и результат. Для проверки удаления через программу выберите тестовый архив, отмените подтверждение и откройте журнал. Повторите с неверным паролем. Успешное удаление проверяйте на архиве, историю которого разрешено удалить.

$testArchive = Read-Host 'Полный путь к закрытому тестовому архиву'
$handle = [IO.File]::Open($testArchive, 'Open', 'Write', 'ReadWrite')
if ($handle) { $handle.Dispose() }

Как снять программу с АРМ

В этом выпуске рабочие компоненты удаляет администратор Windows вручную. Команда «Удалить архив» в окне программы удаляет один закрытый журнал и оставляет сборщик работающим.

  1. Закончите обслуживание архивов. Запишите SID задания сборщика, выполнив schtasks.exe /showsid /tn "\LocalUsbAuditCollector". Остановите сборщик в Планировщике заданий. По согласованному сроку хранения скопируйте активный журнал, архивы или требуемые отчёты в отдельное место. Закройте окно программы.
  2. До удаления установленных сценариев восстановите правила аудита выбранных папок в повышенной Windows PowerShell. Если правила менялись после установки, программа укажет папку. Сверьте её текущую SACL с сохранённой в destinations.json и учтите изменения других администраторов перед продолжением. 
    $appDirectory = Join-Path $env:ProgramFiles 'LocalUsbAudit'
. (Join-Path $appDirectory 'Access.ps1')
. (Join-Path $appDirectory 'DestinationAudit.ps1')
Remove-UsbDestinationAudit -AppDirectory $appDirectory
    Содержимое папок назначения хранится отдельно от журнала. Перед удалением стандартной папки проверьте, какие документы в ней находятся.
  3. Удалите из корня Планировщика задания LocalUsbAuditCollector и LocalUsbAuditMaintenance, а из списка локальных групп — LocalUsbAuditReaders. Назначенный ответственный и читатель используют свои существующие учётные записи Windows.
  4. Удалите установленные сценарии из %ProgramFiles%\LocalUsbAudit. После решения о судьбе истории удалите рабочий каталог %ProgramData%\LocalUsbAudit. Для полного удаления тестовых данных проверьте папку %LOCALAPPDATA%\LocalUsbAudit\Reports каждого пользователя, формировавшего отчёт, и сохранённые вручную копии. Исходный USB-Audit.exe остаётся там, куда его скопировали.
  5. Сверьтесь с записью из раздела «Первый запуск» и с действующей политикой АРМ. Восстановите прежнее состояние аудита успешных событий PnP и съёмных носителей, обоих флагов аудита «Файловая система» и прежнего флага отказа «Управление дескрипторами» (GUID {0CCE9223-69AE-11D9-BED3-505054503030}), прежнее значение или отсутствие HotPlugSecureOpen. В разрешениях канала «Безопасность» удалите добавленное программой право чтения для SID задания сборщика, сохранив изменения других приложений. Удалите регистрацию источника LocalUsbAuditMaintenance в журнале «Приложение», только если он появился при установке.
  6. Проверьте отсутствие обоих заданий, группы читателей и рабочих каталогов. Сверьте системные параметры с исходной записью. Накопленные события в штатных журналах Windows сохраняются до истечения срока хранения, заданного политикой АРМ.

Проверка EXE до установки

Откройте Windows PowerShell в папке с EXE. Встроенная самопроверка проверяет наличие десяти ресурсов, разбирает синтаксис девяти сценариев и ищет в шаблоне HTML место вставки данных. $previousEncoding = [Console]::OutputEncoding

Чтобы увидеть справку, замените --self-test в этой команде на --help. Чтобы извлечь десять рабочих компонентов для независимой сверки, вместо --self-test укажите --extract .\usb-components. Программа создаст папку, если её ещё нет. Для существующей папки требуется пустой каталог. Исходник самого окна и сценарий сборки входят в ZIP выше.

                Console.SetOut(new StreamWriter(Console.OpenStandardOutput(), new UTF8Encoding(false)) { AutoFlush = true });
            if (IsFileOrPipe(-12))
                Console.SetError(new StreamWriter(Console.OpenStandardError(), new UTF8Encoding(false)) { AutoFlush = true });
            if (args.Length == 1 && args[0] == "--help")
            {
                Console.WriteLine("USB-Audit.exe — окно журнала USB.\n" +
                    "--self-test    проверить ресурсы и синтаксис PowerShell\n" +
                    "--extract ПАПКА    извлечь исходные компоненты в пустую папку\n" +
                    "--list-admins    показать доступных локальных администраторов и их SID\n" +
                    "--install SID_ЧИТАТЕЛЯ [SID_АДМИНИСТРАТОРА [--watch-folder ПАПКА]...]    установить с повышенными правами;\n" +
                    "    если второй SID пропущен, откроется окно выбора ответственного за архивы.");
                return 0;
            }
            if (!Environment.Is64BitOperatingSystem || !Environment.Is64BitProcess)
                throw new PlatformNotSupportedException("Требуется 64-разрядная Windows.");
            if (args.Length == 1 && args[0] == "--self-test") { SelfTest(); return 0; }
            if (args.Length == 1 && args[0] == "--list-admins")
            {
                var accounts = LoadAdministrators(false).Accounts;
                if (accounts.Count == 0) Console.WriteLine("Подходящих локальных администраторов нет.");
                foreach (var account in accounts) Console.WriteLine(account.Name + "\t" + account.Sid);
                return 0;
            }
            if (args.Length == 2 && args[0] == "--extract")
            {
                ExtractPublic(args[1]);
                Console.WriteLine("Извлечено компонентов: " + Files.Length);
                return 0;
            }
            if ((args.Length >= 2 && args[0] == "--install") || guiInstaller)
            {
                if (!Role.Admin()) throw new UnauthorizedAccessException("Установка требует прав администратора.");
                string adminSid;
                string[] folders = new string[0];
                if (args.Length >= 3)
                {
                    adminSid = ValidateAccountSid(args[2]);
                    var paths = new List<string>();
                    for (int i=3; i<args.Length; i+=2)
                    {
                        if (args[i] != "--watch-folder" || i+1 >= args.Length)
                            throw new ArgumentException("Укажите --watch-folder и полный путь к папке.");
                        paths.Add(args[i+1]);
                    }
                    folders = paths.ToArray();
                }
                else
                {
                    // В окне после UAC доступны локальные УЗ, даже если оператору запрещено их перечислять.
                    Application.EnableVisualStyles();
                    Application.SetCompatibleTextRenderingDefault(false);
                    using (var chooser = new AdministratorPicker(LoadAdministrators(true)))
                    {
                        if (chooser.ShowDialog() != DialogResult.OK) { Console.WriteLine("Выбор отменён."); return 3; }
                        adminSid = chooser.SelectedSid;
                        folders = chooser.SelectedFolders;
                    }
                }
                Install(ValidateAccountSid(args[1]), adminSid, folders);
                Console.WriteLine("Установка завершена.");
                return 0;
            }
            Console.Error.WriteLine("Неизвестная команда. Выполните USB-Audit.exe --help.");
            return 2;
        }
        catch (Exception error)
        {
            if (args.Length == 0 || guiInstaller)
                MessageBox.Show(error.Message, Title, MessageBoxButtons.OK, MessageBoxIcon.Error);
            Console.Error.WriteLine(error.Message);
            return 1;
        }
    }

    private static byte[] Resource(string name)
    {
        using (Stream resource = Assembly.GetExecutingAssembly().GetManifestResourceStream(name))
        {
            if (resource == null || resource.Length == 0) throw new InvalidDataException("Отсутствует компонент " + name);
            using (MemoryStream buffer = new MemoryStream())
            {
                resource.CopyTo(buffer);
                return buffer.ToArray();
            }
        }
    }

    // Сверяем состав ресурсов, печатаем их SHA-256 и разбираем сценарии штатным парсером PowerShell.
    private static void SelfTest()
    {
        if (!new HashSet<string>(Files).SetEquals(Assembly.GetExecutingAssembly().GetManifestResourceNames()))
            throw new InvalidDataException("Состав ресурсов отличается от ожидаемого.");
        StringBuilder source = new StringBuilder();
        using (SHA256 sha = SHA256.Create())
        foreach (string file in Files)
        {
            byte[] contents = Resource(file);
            string text = Utf8.GetString(contents).TrimStart('\ufeff');
            if (file == "viewer.html")
            {
                if (!text.Contains("<!-- USB-AUDIT-DATA -->")) throw new InvalidDataException("Повреждён шаблон отчёта.");
            }
            else
                source.AppendLine(file + " " + Convert.ToBase64String(Utf8.GetBytes(text)));
            Console.WriteLine(BitConverter.ToString(sha.ComputeHash(contents)).Replace("-", "") + "  " + file);
        }
        string parser =
            "while ($null -ne ($s=[Console]::ReadLine())) {" +
            "$i=$s.IndexOf(' ');$name=$s.Substring(0,$i);$data=[Convert]::FromBase64String($s.Substring($i+1));" +

            "[Text.Encoding]::UTF8.GetString($data),[ref]$tok,[ref]$err);" +
            "if($err.Count){throw ($name+' '+$err[0].Message)}}; exit 0";
        PsResult result = PowerShell(parser, Environment.SystemDirectory, source.ToString(), null);
        result.RequireSuccess();
        Console.WriteLine("OK: {0} ресурсов, {1} сценариев PowerShell, шаблон HTML.", Files.Length, Files.Length-1);
    }

    private static void CheckNoLinks(string path)

    private static void WriteResources(string directory)
    {
        List<string> created = new List<string>();
        try
        {
            foreach (string name in Files)

                }
            }

            throw;
        }
    }

    internal static AdminCatalog LoadAdministrators(bool includeRegistration)
    {
        // Access.ps1 читаем из собственного ресурса. Пути и команды от пользователя в код не подставляются.
        const string source =
            "$code=[Text.Encoding]::UTF8.GetString([Convert]::FromBase64String([Console]::In.ReadToEnd())).TrimStart([char]0xfeff);" +
            ". ([scriptblock]::Create($code));" +
            "function ToText64([string]$value){[Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($value))};";
        const string registration =
            "Assert-RegularPath $meta;" +
            "if(Test-Path -LiteralPath $meta -PathType Leaf){" +
            "$cfg=Get-Content -LiteralPath $meta -Raw -Encoding UTF8|ConvertFrom-Json;" +
            "if($cfg.format -ne 'local-usb-audit-v1'){throw 'Неизвестный формат существующей установки.'};" +
            "[Console]::WriteLine('existing');" +
            "if($cfg.custodianMode -ceq 'ExistingAdmin' -and $cfg.custodianSid){" +
            "[Console]::WriteLine(('saved'+[char]9+$cfg.custodianSid+[char]9+(ToText64 $cfg.custodianAccount)))}};";
        const string destinations =
            "$dest=Join-Path (Split-Path -LiteralPath $meta) 'destinations.json';Assert-RegularPath $dest;" +
            "if([IO.File]::Exists($dest)){$conf=[IO.File]::ReadAllText($dest)|ConvertFrom-Json;" +
            "foreach($f in $conf.folders){[Console]::WriteLine(('folder'+[char]9+(ToText64 $f.path)))}};";
        const string candidates =
            "foreach($u in @(Get-UsbLocalAdministrators | Sort-Object Name)){" +
            "$name=[Environment]::MachineName+[char]92+$u.Name;" +
            "[Console]::WriteLine(('user'+[char]9+$u.SID.Value+[char]9+(ToText64 $name)))}";
        string command = source + (includeRegistration ? registration + destinations : "") + candidates;
        // Windows PowerShell компилирует встроенный вызов NetAPI во временной папке.
        // При высоких правах используем закрытый каталог с ACL SYSTEM/Администраторы.
        string stage = Role.Admin() ? NewStage() : null;
        PsResult result;
        try
        {
            var environment = stage == null ? null : new Dictionary<string,string>{{"TEMP",stage},{"TMP",stage}};
            result = PowerShell(command, Environment.SystemDirectory,
                Convert.ToBase64String(Resource("Access.ps1")), environment);
        }
        finally { if (stage != null) RemoveDirectoryTree(new DirectoryInfo(stage)); }
        result.RequireSuccess();
        var catalog = new AdminCatalog();
        foreach (string line in result.Output.Split(new[]{'\r','\n'}, StringSplitOptions.RemoveEmptyEntries))
        {
            if (line.StartsWith("folder\t",StringComparison.Ordinal))
            {
                catalog.Folders.Add(Utf8.GetString(Convert.FromBase64String(line.Substring(7))));
                continue;
            }
            if (line == "existing") { catalog.PreviousInstallation = true; continue; }
            string[] values = line.Split('\t');
            if (values.Length != 3 || (values[0] != "saved" && values[0] != "user"))
                throw new InvalidDataException("Не удалось прочитать список администраторов.");
            string sid = ValidateAccountSid(values[1]);
            string name = Utf8.GetString(Convert.FromBase64String(values[2]));
            if (values[0] == "saved") { catalog.ConfiguredSid=sid; catalog.ConfiguredName=name; }
            else catalog.Accounts.Add(new AdminAccount {Name=name, Sid=sid});
        }
        return catalog;
    }

    }

    // PowerShell передаёт часть ошибок в CLIXML. В диалоге показываем текст ошибки.
    private static string ReadErrors(string raw)
    {
        string messages = Regex.Replace(raw, @"<Objs\b[^>]*>[\s\S]*?</Objs>", delegate(Match block)
        {
            var xml = new XmlDocument { XmlResolver = null };
            var settings = new XmlReaderSettings { DtdProcessing = DtdProcessing.Prohibit, XmlResolver = null };
            try
            {
                using (XmlReader reader = XmlReader.Create(new StringReader(block.Value), settings)) xml.Load(reader);
                var lines = new List<string>();
                foreach (XmlNode item in xml.DocumentElement.ChildNodes)
                {
                    var record = item as XmlElement;
                    if (record == null || !String.Equals(record.GetAttribute("S"), "Error", StringComparison.OrdinalIgnoreCase)) continue;
                    XmlNode message = record.LocalName == "S" ? record :
                        record.SelectSingleNode("./*[local-name()='ToString']");
                    if (message != null) lines.Add(XmlConvert.DecodeName(message.InnerText).Trim());
                }
                return String.Join(Environment.NewLine, lines);
            }
            catch (XmlException) { return "Windows PowerShell вернула повреждённое сообщение об ошибке."; }
        });
        return Regex.Replace(messages, @"(?m)^\s*#< CLIXML[ \t]*\r?$", "").Trim();
    }

    // Параметры передаются как значения; текст команд постоянен. Пароль не входит в командную строку.
    private static PsResult PowerShell(string body, string directory,
        string input, Dictionary<string, string> environment)
    {
        string script = "$ErrorActionPreference='Stop';[Console]::OutputEncoding=[Text.UTF8Encoding]::new($false);" +
            "try{" + body + "}catch{[Console]::Error.WriteLine($_.Exception.Message);exit 1}";
        string encoded = Convert.ToBase64String(Encoding.Unicode.GetBytes(script));
        ProcessStartInfo start = new ProcessStartInfo(NativePowerShell,
            "-NoLogo -NoProfile -NonInteractive -ExecutionPolicy Bypass " +
            "-EncodedCommand " + encoded);
        start.UseShellExecute = false;
        start.WorkingDirectory = directory;
        start.CreateNoWindow = true;
        start.RedirectStandardError = true;
        start.StandardErrorEncoding = Encoding.UTF8;
        start.RedirectStandardOutput = true;
        start.StandardOutputEncoding = Encoding.UTF8;
        start.RedirectStandardInput = input != null;
        if (environment != null)
            foreach (KeyValuePair<string,string> item in environment) start.EnvironmentVariables[item.Key] = item.Value;
        // Загружаем модули и системные утилиты из каталогов, доступных для записи администраторам.
        start.EnvironmentVariables["PSModulePath"] =
            Path.Combine(ProgramRoot, @"WindowsPowerShell\Modules") + ";" +
            Path.Combine(Environment.SystemDirectory, @"WindowsPowerShell\v1.0\Modules");
        start.EnvironmentVariables["Path"] = Environment.SystemDirectory + ";" + SystemRoot + ";" +
            Path.Combine(Environment.SystemDirectory, "Wbem") + ";" +
            Path.Combine(Environment.SystemDirectory, @"WindowsPowerShell\v1.0");
        // Системные пути получаем от Windows и не наследуем их значения от вызывающего процесса.
        start.EnvironmentVariables["SystemRoot"] = start.EnvironmentVariables["windir"] = SystemRoot;
        start.EnvironmentVariables["ProgramFiles"] = ProgramRoot;
        start.EnvironmentVariables["ProgramData"] = Environment.GetFolderPath(Environment.SpecialFolder.CommonApplicationData);
        start.EnvironmentVariables["ComSpec"] = Path.Combine(Environment.SystemDirectory, "cmd.exe");
        using (Process process = Process.Start(start))
        {
            Task<string> errors = process.StandardError.ReadToEndAsync();
            Task<string> output = process.StandardOutput.ReadToEndAsync();
            if (input != null)
            {
                process.StandardInput.Write(input);
                process.StandardInput.Close();
            }
            process.WaitForExit();
            return new PsResult {Code=process.ExitCode, Errors=ReadErrors(errors.Result), Output=output.Result};
        }
    }

    private static extern bool ReportEvent(IntPtr handle, ushort type, ushort category, uint id,

    // Читатель сообщает о выборе в Windows Application. Права записи в защищённый журнал ему не выдаются.
    internal static void NoteArchiveChoice(string archive, int id)
    {
        if (archive==null || !ArchivePattern.IsMatch(archive) || id<4101 || id>4103)
            throw new ArgumentException("Некорректное событие интерфейса.");
        using (var identity=WindowsIdentity.GetCurrent())
        {
            var sid=new byte[identity.User.BinaryLength];
            identity.User.GetBinaryForm(sid,0);
            IntPtr handle=RegisterEventSource(null,"LocalUsbAuditMaintenance");
            if (handle==IntPtr.Zero) throw new Win32Exception(Marshal.GetLastWin32Error());
            try {
                if (!ReportEvent(handle,4,0,(uint)id,sid,1,0,new[]{archive},IntPtr.Zero))
                    throw new Win32Exception(Marshal.GetLastWin32Error());
            } finally { DeregisterEventSource(handle); }
        }
    }

    internal static ProcessStartInfo MaintenanceStart(string action, string archive)

        string arguments = "-NoLogo -NoProfile -ExecutionPolicy RemoteSigned -File \"" +

    // Перед вызовом UAC проверяем возможность подмены системного исполняемого файла и рабочего каталога.
    private static void CheckProtectedAcl(FileSystemSecurity security, bool systemFile)
    {
        const string installer = "S-1-5-80-956008885-3418522649-1831038044-1853292631-2271478464";
        Func<string,bool> trusted = sid => sid=="S-1-5-18" || sid=="S-1-5-32-544" || (systemFile && sid==installer);
        var descriptor=new RawSecurityDescriptor(security.GetSecurityDescriptorBinaryForm(),0);
        if (descriptor.DiscretionaryAcl==null || !trusted(descriptor.Owner.Value))
            throw new IOException("У защищённого пути неподходящий владелец или отсутствует список разрешений.");
        const FileSystemRights writes = FileSystemRights.Write | FileSystemRights.Delete | FileSystemRights.DeleteSubdirectoriesAndFiles |
            FileSystemRights.ChangePermissions | FileSystemRights.TakeOwnership;
        foreach (FileSystemAccessRule rule in security.GetAccessRules(true,true,typeof(SecurityIdentifier)))
        {
            if (rule.AccessControlType!=AccessControlType.Allow || trusted(rule.IdentityReference.Value) ||
                (rule.PropagationFlags & PropagationFlags.InheritOnly)!=0) continue;
            if ((((uint)rule.FileSystemRights) & (0x50000000u | (uint)writes))!=0)
                throw new IOException("Права доступа допускают подмену рабочего компонента. Обратитесь к администратору.");
        }
    }

    private static FileStream OpenVerifiedResource(string name)
    {
        string path=Path.Combine(Installed,name);
        if ((File.GetAttributes(path) & FileAttributes.ReparsePoint) != 0)
            throw new IOException("Рабочий компонент является ссылкой: " + name);
        var stream=new FileStream(path,FileMode.Open,FileAccess.Read,FileShare.Read);
        try
        {
            using (SHA256 sha=SHA256.Create())
                if (!sha.ComputeHash(stream).SequenceEqual(sha.ComputeHash(Resource(name))))
                    throw new InvalidDataException("Контрольная сумма " + name +
                        " отличается. Откройте EXE установленной версии или выполните согласованное обновление.");
            return stream;
        }
        catch { stream.Dispose(); throw; }
    }

    private static PsResult Maintain(string action, string archive)
    {
        ProcessStartInfo start = MaintenanceStart(action, archive);
        CheckNoLinks(Path.GetDirectoryName(start.FileName));
        if ((File.GetAttributes(start.FileName) & FileAttributes.ReparsePoint) != 0)
            throw new IOException("Путь к системной Windows PowerShell перенаправлен.");
        CheckProtectedAcl(File.GetAccessControl(start.FileName),true);
        CheckNoLinks(Installed);
        CheckProtectedAcl(Directory.GetAccessControl(Installed),false);
        // Обслуживание требует установленных файлов той же версии, что и открытый EXE.
        // До завершения операции удерживаем эти файлы открытыми с запретом записи и удаления.
        using (OpenVerifiedResource("ArchiveAudit.ps1"))
        using (OpenVerifiedResource("Maintenance.ps1"))
        using (OpenVerifiedResource("Access.ps1"))
        try
        {
            using (Process child=Process.Start(start))
            {
                child.WaitForExit();
                return new PsResult {Code=child.ExitCode, Output="", Errors=child.ExitCode==0 ? "" :
                    "Обслуживание не подтвердило успех. Подробности приведены в окне Windows PowerShell. Код " + child.ExitCode + "."};
            }
        }
        catch (Win32Exception error)
        {
            if (error.NativeErrorCode!=1223) throw;
            if (action=="delete") NoteArchiveChoice(archive,4103);
            return new PsResult {Code=1223, Output="", Errors="Запрос UAC отменён. Операция с архивом не запущена."};
        }
    }

    // Шаблон и сценарий берём из открытого EXE, чтобы уже собранные журналы
    // можно было просмотреть новой версией без перезапуска или обновления сборщика.
    private static PsResult GenerateReport(string archive)
    {
        const string command =
            "$code=[Text.Encoding]::UTF8.GetString([Convert]::FromBase64String([Console]::ReadLine())).TrimStart([char]0xfeff);" +
            "$viewer=[Text.Encoding]::UTF8.GetString([Convert]::FromBase64String([Console]::In.ReadToEnd()));" +
            "$options=@{ViewerTemplate=$viewer;NoOpen=$true};" +
            "if($env:LOCALUSBAUDIT_ARCHIVE){$options.ArchiveName=$env:LOCALUSBAUDIT_ARCHIVE};" +
            "& ([scriptblock]::Create($code)) @options";
        string input = Convert.ToBase64String(Resource("Report.ps1")) + "\n" +
            Convert.ToBase64String(Resource("viewer.html"));
        var environment = new Dictionary<string,string>{{"LOCALUSBAUDIT_ARCHIVE", archive ?? ""}};
        return PowerShell(command, Environment.SystemDirectory, input, environment);
    }

    // Отчёт открывается с правами текущего читателя. Диагностика относится к установленному сборщику.
    internal static PsResult Script(string action, string archive)
    {
        CheckNoLinks(Installed);
        if (archive != null && !ArchivePattern.IsMatch(archive))
            throw new ArgumentException("Недопустимое имя закрытого архива.");
        PsResult result;
        switch (action)
        {
            case "report":
                result = GenerateReport(archive);
                break;
            case "check":
                result = PowerShell("& .\\Check.ps1;exit $LASTEXITCODE", Installed, null, null);
                break;
            case "rotate":
            case "delete": return Maintain(action, archive);
            default: throw new ArgumentException("Неизвестная операция.");
        }
        if (action == "report" && result.Code == 0)
        {
            string report = Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData),
                @"LocalUsbAudit\Reports\USB-Audit.html");
            if (!File.Exists(report)) throw new FileNotFoundException("Отчёт не найден после формирования.", report);
            Process.Start(new ProcessStartInfo(report) {UseShellExecute=true});
        }
        return result;
    }
}

        }
    }
    Write-Host "Проверено: сборщик читает Security и записывает журнал. Группа для просмотра: $readersName. Проверка: $app\Check.ps1"
    Write-Host "За обслуживание архивов отвечает $account."
    Write-Host 'После добавления в группу читателей выйдите из Windows и войдите снова. Переподключите тестовый СНИ и проверьте запись и чтение файла по имени.'

    if ($lockedSubmit) { $lockedSubmit.Dispose() }
    $setupLock.Dispose()
    if ($restartPriorCollector) {
        try { Start-ScheduledTask -TaskName $collectorTask }
        catch { Write-Warning "Не удалось возобновить работу сборщика: $_" }
    }
}

function Get-UsbLocalAdministrators {

    # Уровень 0 возвращает SID участников без разрешения удалённых и доменных имён.
    if (!('LocalUsbAudit.LocalAdminGroup' -as [type])) {

using System.ComponentModel;
using System.Runtime.InteropServices;
using System.Security.Principal;
namespace LocalUsbAudit {
    public static class LocalAdminGroup {
        [DllImport("netapi32.dll", CharSet=CharSet.Unicode)]
        static extern int NetLocalGroupGetMembers(string server, string group, int level,
            out IntPtr buffer, int maxBytes, out int count, out int total, ref UIntPtr resume);
        [DllImport("netapi32.dll")]
        static extern int NetApiBufferFree(IntPtr buffer);
        public static HashSet<string> DirectMemberSids(string group) {
            var result = new HashSet<string>(StringComparer.OrdinalIgnoreCase);

function Get-SelectedLocalAdmin([string]$Sid) {

}

function Set-RequestPaths($Config) {
    # Своя очередь для каждого назначения отделяет новые команды от старых запросов.
    # Старая установка хранит request.json и result.json без суффикса.
    $suffix = ''
    if ($Config.requestGeneration) {
        if ([string]$Config.requestGeneration -cnotmatch '\A[0-9a-f]{32}\z') { throw 'Некорректный идентификатор очереди обслуживания.' }
        $suffix = '-' + $Config.requestGeneration
    } elseif ($Config.custodianMode -eq 'ExistingAdmin') { throw 'В конфигурации отсутствует идентификатор очереди обслуживания.' }
    $script:requestFile = Join-Path $stage ("request$suffix.json")
    $script:responseFile = Join-Path $stage ("result$suffix.json")
    $script:intentFile = Join-Path $stage ("intent$suffix.json")
    $script:submitFile = Join-Path $stage ("submit$suffix.lock")
}

function Assert-RegularPath([string]$Path) {
    # Проверяем всех предков, чтобы ссылка не перенаправила запись в другой каталог.
    $full = [IO.Path]::GetFullPath($Path)
    while ($full) {
        try {
            $attributes = [IO.File]::GetAttributes($full)
            if (($attributes -band [IO.FileAttributes]::ReparsePoint) -ne 0) {
                throw "Точка повторного анализа в защищённом пути: $full"
            }
        } catch [IO.FileNotFoundException] {
        } catch [IO.DirectoryNotFoundException] {
        }
        $parent = [IO.Directory]::GetParent($full)
        if (!$parent) { break }
        $full = $parent.FullName
    }
}

function Set-GuardedDirectory([string]$Path, [string]$Sddl) {
    Assert-RegularPath $Path
    $security = [Security.AccessControl.DirectorySecurity]::new()
    $security.SetSecurityDescriptorSddlForm($Sddl)
    if ([IO.Directory]::Exists($Path)) {
        $owner = [IO.Directory]::GetAccessControl($Path).GetOwner([Security.Principal.SecurityIdentifier]).Value
        if ($owner -notin 'S-1-5-18','S-1-5-32-544') { throw "Недоверенный владелец каталога: $Path" }
        [IO.Directory]::SetAccessControl($Path,$security)
    } else {
        [void][IO.Directory]::CreateDirectory($Path,$security)
    }
}

function Set-GuardedFile([string]$Path, [string]$Sddl) {
    Assert-RegularPath $Path
    $security = [Security.AccessControl.FileSecurity]::new()
    $security.SetSecurityDescriptorSddlForm($Sddl)
    if ([IO.File]::Exists($Path)) {
        $owner = [IO.File]::GetAccessControl($Path).GetOwner([Security.Principal.SecurityIdentifier]).Value
        if ($owner -notin 'S-1-5-18','S-1-5-32-544') { throw "Недоверенный владелец файла: $Path" }
        [IO.File]::SetAccessControl($Path,$security)
    } else {
        $handle = [IO.FileStream]::new($Path,[IO.FileMode]::CreateNew,
            [Security.AccessControl.FileSystemRights]::FullControl,[IO.FileShare]::ReadWrite,
            4096,[IO.FileOptions]::None,$security)
        $handle.Dispose()
    }
}

function Get-FileRules($Config, [switch]$WritableLog) {
    $sddl = $baseFile + "(A;;FR;;;$($Config.readersSid))(A;;FR;;;$($Config.custodianSid))"
    # Сборщик может читать активный журнал и только дописывать в его конец.
    if ($WritableLog) { $sddl += "(A;;0x12008d;;;$($Config.taskSid))" }
    return $sddl
}

function Enter-FileLock([string]$Path, [int]$Seconds = 30) {
    $until = [DateTime]::UtcNow.AddSeconds($Seconds)
    do {
        try { return [IO.File]::Open($Path,'Open','ReadWrite','None') }
        catch [IO.IOException] { if ([DateTime]::UtcNow -ge $until) { throw }; Start-Sleep -Milliseconds 150 }
    } while ($true)

# Обычная запись через FileStream может потребовать также право менять прежнее содержимое.
Add-Type -TypeDefinition @'
using System;
using System.Text;
using System.ComponentModel;
using System.Runtime.InteropServices;
using Microsoft.Win32.SafeHandles;

public static class UsbAuditNative {
    [DllImport("kernel32.dll", CharSet=CharSet.Unicode, SetLastError=true)]
    static extern SafeFileHandle CreateFile(string name, uint access, uint share,
        IntPtr security, uint mode, uint options, IntPtr template);
    [DllImport("kernel32.dll", SetLastError=true)]
    static extern bool WriteFile(SafeFileHandle file, byte[] bytes, int count,
        out int written, IntPtr overlapped);
    [DllImport("kernel32.dll", CharSet=CharSet.Unicode, SetLastError=true)]
    static extern bool MoveFileEx(string oldName, string newName, uint flags);
    [DllImport("kernel32.dll", CharSet=CharSet.Unicode, SetLastError=true)]
    static extern uint QueryDosDevice(string device, StringBuilder value, int size);
    [DllImport("kernel32.dll", CharSet=CharSet.Unicode, SetLastError=true)]
    static extern bool GetVolumeNameForVolumeMountPoint(string path, StringBuilder name, int size);
    [DllImport("cfgmgr32.dll", CharSet=CharSet.Unicode)]
    static extern int CM_Locate_DevNodeW(out uint node, string id, uint flags);
    [DllImport("cfgmgr32.dll")]
    static extern int CM_Get_Parent(out uint parent, uint node, uint flags);
    [DllImport("cfgmgr32.dll", CharSet=CharSet.Unicode)]
    static extern int CM_Get_Device_IDW(uint node, StringBuilder id, int size, uint flags);

    public static void Append(string path, byte[] data) {
        using(var h = CreateFile(path, 4, 7, IntPtr.Zero, 3, 0x80000000, IntPtr.Zero)) {
            if (h.IsInvalid) throw new Win32Exception(Marshal.GetLastWin32Error());
            int written;
            if (!WriteFile(h, data, data.Length, out written, IntPtr.Zero))
                throw new Win32Exception(Marshal.GetLastWin32Error());
            if (written != data.Length) throw new System.IO.IOException("Incomplete journal write");
        }
    }
    public static void ReplaceState(string temporary, string destination) {
        if (!MoveFileEx(temporary,destination,1|8))
            throw new Win32Exception(Marshal.GetLastWin32Error());
    }
    public static string NtName(string alias) {
        var value = new StringBuilder(32768);
        return QueryDosDevice(alias, value, value.Capacity) == 0 ? null : value.ToString();
    }
    public static string VolumeName(string root) {
        var value = new StringBuilder(1024);
        return GetVolumeNameForVolumeMountPoint(root, value, value.Capacity) ? value.ToString() : null;
    }
    public static bool IsUsb(string id) {
        uint node, parent;
        if (String.IsNullOrEmpty(id) || CM_Locate_DevNodeW(out node, id, 0) != 0) return false;
        for (int depth=0; depth<32; depth++) {
            var name = new StringBuilder(1024);
            if (CM_Get_Device_IDW(node, name, name.Capacity, 0) != 0) break;
            if (name.ToString().StartsWith(@"USB\",StringComparison.OrdinalIgnoreCase)) return true;
            if (CM_Get_Parent(out parent,node,0)!=0) break;
            node=parent;
        }
        return false;
    }
}

function Save-Checkpoint {
    $temp = $checkpoint + '.tmp'
    $json = $state | ConvertTo-Json -Compress -Depth 14
    $bytes = $utf8.GetBytes($json)
    $stream = [IO.File]::Open($temp,'Create','Write','None')
    try { $stream.Write($bytes,0,$bytes.Length); $stream.Flush($true) } finally { $stream.Dispose() }
    [UsbAuditNative]::ReplaceState($temp,$checkpoint)
}
function Publish-Pending {
    if (@($state.pending).Count -eq 0) { return }
    $lines = foreach ($record in $state.pending) { $record | ConvertTo-Json -Compress -Depth 12 }
    # Перевод строки отделяет новую запись от возможного незавершённого хвоста журнала.
    $bytes = $utf8.GetBytes("`n" + ($lines -join "`n") + "`n")
    $published=$false
    for ($n = 0; $n -lt 60; $n++) {
        $lock=$null
        try {
            $lock=[IO.File]::Open($journalLock,'Open','ReadWrite','None')
            [UsbAuditNative]::Append($journal,$bytes)
            $published=$true
            break
        } catch {
            $cause=$_.Exception.GetBaseException()
            $sharing=($cause -is [ComponentModel.Win32Exception] -and $cause.NativeErrorCode -in 32,33) -or
                ($cause -is [IO.IOException] -and ($cause.HResult -band 0xFFFF) -in 32,33)
            if (!$sharing) { throw }
        } finally { if ($lock) { $lock.Dispose() } }
        Start-Sleep -Milliseconds 200
    }
    if (!$published) { throw 'Journal is busy. The batch is saved in the checkpoint for retry.' }
    $state.pending = @()
    Save-Checkpoint
}
function Commit-State {
    # После аварии порция записей может попасть в журнал повторно. Постоянные идентификаторы
    # позволяют отличить повторную доставку от нового действия того же пользователя.
    $state.pending = $script:pending.ToArray()
    Save-Checkpoint
    Publish-Pending
    $script:pending.Clear()
}

# У одного физического СНИ может быть несколько томов. Сохраняем их буквы, GUID и имена Windows для поиска пути из события.
function Get-DiskVolumes($Disk) {
    $number = [int]$Disk.Index
    try {
        $parts = @(Get-CimInstance -Namespace 'root/Microsoft/Windows/Storage' -ClassName MSFT_Partition -Filter "DiskNumber=$number")
        $partPaths = foreach ($part in $parts) {
            [pscustomobject]@{ paths = @($part.AccessPaths | Where-Object { $_ }) }
        }
    } catch {
        # Если службе недоступен класс Storage, узнаём буквы томов через связи Win32.
        $parts = @(Get-CimInstance Win32_DiskPartition -Filter "DiskIndex=$number")
        $partPaths = foreach ($part in $parts) {
            $logical = @(Get-CimAssociatedInstance -InputObject $part -Association Win32_LogicalDiskToPartition)
            [pscustomobject]@{ paths = @($logical | ForEach-Object { $_.DeviceID + '\' }) }
        }
    }
    foreach ($part in $partPaths) {
        $paths = @($part.paths)
        $letter = $null
        foreach ($path in $part.paths) {
            if ($path -match '^[A-Za-z]:\\?$') { $letter = $path.Substring(0,2) }
            if ($path -match '^\\\\\?\\Volume\{') {
                $paths += [UsbAuditNative]::NtName($path.Substring(4).TrimEnd('\'))
            } elseif ($path.EndsWith('\')) {
                $guid = [UsbAuditNative]::VolumeName($path)
                if ($guid) {
                    $paths += $guid
                    $paths += [UsbAuditNative]::NtName($guid.Substring(4).TrimEnd('\'))
                }
            }
        }
        if ($letter) { $paths += [UsbAuditNative]::NtName($letter) }
        $paths = @($paths | Where-Object { $_ } | Sort-Object -Unique)
        if ($paths.Count) { [pscustomobject]@{letter=$letter; paths=$paths} }
    }
}

# PnP-идентификатор и серийный номер берём из разных свойств диска. Поле серийного номера может быть пустым.
function Get-UsbSnapshot {
    $result = @{}
    foreach ($disk in (Get-CimInstance Win32_DiskDrive -Property Index,InterfaceType,PNPDeviceID,SerialNumber,Model)) {
        $id = [string]$disk.PNPDeviceID
        if (!$id) { continue }
        # По родительским устройствам PnP распознаём и USB-корпуса, зарегистрированные как SCSI.
        if ($disk.InterfaceType -ne 'USB' -and $id -notlike 'USBSTOR\*' -and ![UsbAuditNative]::IsUsb($id)) { continue }
        $serial = ([string]$disk.SerialNumber).Trim()
        if (!$serial) { $serial = $null }
        $result[$id] = [pscustomobject]@{
            deviceId=$id; serial=$serial; model=[string]$disk.Model
            volumes=@(Get-DiskVolumes $disk)
        }
    }
    return $result
}

function Close-Session($Item, [datetime]$Time, [string]$EndSource) {
    $Item.end = Get-UtcText $Time
    foreach ($binding in $Item.bindings) {
        if ($binding.end) { continue }
        $binding.end=$Item.end
        # Между опросами буква или папка монтирования могла перейти другому тому.
        # Системное имя тома позволяет привязать запись даже непосредственно перед извлечением.
        if ($EndSource -eq 'inventory' -and $binding.path -match '^[a-z]:') { $binding.end=$Item.lastSeen }
    }
    $type=if ($EndSource -in 'volumeEvent','inventory') { 'disconnect' } else { 'end_unknown' }
    Add-SessionRecord $type $Time $Item $EndSource
}
function Refresh-Inventory($Snapshot, $Signals, [datetime]$Now) {
    $open = @{}
    foreach ($s in $state.sessions) { if (!$s.end) { $open[$s.deviceId]=$s } }
    foreach ($id in $open.Keys) {
        $s=$open[$id]
        $letters=@($s.volumes | ForEach-Object { $_.letter } | Where-Object { $_ })
        $removals=@($Signals | Where-Object { $_.kind -eq 3 -and $_.letter -in $letters -and $_.time -ge (Get-Instant $s.start) -and $_.time -le $Now })
        $removed=$null
        if ($letters.Count -and $letters.Count -eq @($s.volumes).Count) {
            $firstByLetter=@($removals | Group-Object letter | ForEach-Object { $_.Group | Sort-Object time | Select-Object -First 1 })
            if ($firstByLetter.Count -eq $letters.Count) {
                $removed=$firstByLetter | Sort-Object time -Descending | Select-Object -First 1
            }
        }
        # Уведомление об извлечении тома может прийти раньше, чем исчезнет сам диск.
        # Сохраняем его за этим сеансом, даже если буквы томов пропадут при следующем опросе.
        if ($removed) { $s.removalSignal=[pscustomobject]@{time=Get-UtcText $removed.time;letters=$letters} }
        elseif ($s.removalSignal -and ($Now-(Get-Instant $s.removalSignal.time)).TotalSeconds -gt 15) { $s.removalSignal=$null }
        $removalTime=$null
        $insertedAgain=$false
        if ($s.removalSignal) {
            $removalTime=Get-Instant $s.removalSignal.time
            $insertedAgain=@($Signals | Where-Object { $_.kind -eq 2 -and $_.letter -in $s.removalSignal.letters -and $_.time -ge $removalTime -and $_.time -le $Now }).Count -gt 0
        }
        $present=$Snapshot.ContainsKey($id)
        if ($removalTime -and (!$present -or $insertedAgain)) {
            if ($s.firstAbsent -and $removalTime -gt (Get-Instant $s.firstAbsent)) {
                Close-Session $s (Get-Instant $s.firstAbsent) 'inventory'
            } else { Close-Session $s $removalTime 'volumeEvent' }
        } elseif (!$present) {
            # Один снимок может пропустить устройство. Повторное отсутствие подтверждает
            # отключение; время первого отсутствия является верхней границей интервала.
            if ($s.firstAbsent) { Close-Session $s (Get-Instant $s.firstAbsent) 'inventory' }
            else { $s.firstAbsent=Get-UtcText $Now }
        } elseif ($s.firstAbsent) {
            $absent=Get-Instant $s.firstAbsent
            $newLetters=@($Snapshot[$id].volumes | ForEach-Object { $_.letter } | Where-Object { $_ })
            $arrivalAfterAbsence=$Signals | Where-Object {
                $_.kind -eq 2 -and $_.letter -in $newLetters -and $_.time -ge $absent -and $_.time -le $Now
            } | Select-Object -First 1
            if ($arrivalAfterAbsence) { Close-Session $s $absent 'inventory' }
            else { $s.firstAbsent=$null }
        }
    }
    foreach ($device in $Snapshot.Values) {
        $id = $device.deviceId
        $paths = @(Get-Paths $device.volumes)
        $letters = @($device.volumes | ForEach-Object { $_.letter } | Where-Object { $_ })
        $s = $open[$id]
        if (!$s -or $s.end) {
            $arrival = $Signals | Where-Object { $_.kind -eq 2 -and $_.letter -in $letters } | Sort-Object time -Descending | Select-Object -First 1
            $start=$Now
            if ($arrival -and $arrival.time -le $Now -and (!$s -or $arrival.time -ge (Get-Instant $s.end))) { $start=$arrival.time }
            $s=[pscustomobject]@{session=[guid]::NewGuid().ToString(); deviceId=$id; serial=$device.serial; model=$device.model
                start=Get-UtcText $start; end=$null; lastSeen=Get-UtcText $Now; firstAbsent=$null; removalSignal=$null
                observedOnly=($start -eq $Now); volumes=$device.volumes; bindings=@()}
            foreach ($path in $paths) { $s.bindings+= [pscustomobject]@{path=$path;start=$s.start;end=$null} }
            $state.sessions+= $s
            Add-SessionRecord 'connect' $start $s
        } else {
            $formerly=@($s.bindings | Where-Object { !$_.end } | ForEach-Object { $_.path })
            $changed=$false
            $unmounted=$s.lastSeen
            if ($s.removalSignal -and (Get-Instant $s.removalSignal.time) -ge (Get-Instant $s.lastSeen)) {
                $unmounted=$s.removalSignal.time
            }
            foreach ($b in $s.bindings) {
                if (!$b.end -and $b.path -notin $paths) { $b.end=$unmounted; $changed=$true }
            }
            foreach ($path in $paths) {
                if ($path -notin $formerly) {
                    $since=$Now
                    $mount=$device.volumes | Where-Object { $path -in @($_.paths | ForEach-Object { $_.TrimEnd('\') }) } | Select-Object -First 1
                    $arrival = $Signals | Where-Object { $_.kind -eq 2 -and $_.letter -eq $mount.letter } | Sort-Object time -Descending | Select-Object -First 1
                    if ($arrival -and $arrival.time -ge (Get-Instant $s.start) -and $arrival.time -le $Now) { $since=$arrival.time }
                    $s.bindings+= [pscustomobject]@{path=$path;start=Get-UtcText $since;end=$null}
                    $changed=$true
                }
            }
            $s.volumes=$device.volumes
            $s.lastSeen=Get-UtcText $Now
            if ($changed) { New-Entry 'status' $Now @{kind='volumes';session=$s.session;volumes=$s.volumes;message='Изменились точки подключения тома.'} }
        }
    }
}

function New-SecurityReader([string]$XPath, [bool]$Reverse) {
    $query = New-Object System.Diagnostics.Eventing.Reader.EventLogQuery('Security','LogName',$XPath)
    $query.ReverseDirection = $Reverse
    return New-Object System.Diagnostics.Eventing.Reader.EventLogReader($query)
}
function Get-LogAnchor([string]$XPath, [bool]$Reverse) {
    $reader=New-SecurityReader $XPath $Reverse
    try {
        $record=$reader.ReadEvent()
        if ($record) {
            try { return [pscustomobject]@{id=[long]$record.RecordId;time=Get-UtcText ($record.TimeCreated)} }
            finally { $record.Dispose() }
        }
    } finally { $reader.Dispose() }
}
function Get-AccessDescription([uint32]$Mask) {
    $words=@()
    # Младшие биты маски имеют разные значения для файла и для каталога.
    if ($Mask -band 1) { $words+='Чтение данных / списка каталога' }
    if ($Mask -band 2) { $words+='Запись данных / создание файла' }
    if ($Mask -band 4) { $words+='Добавление данных / создание каталога' }
    if ($Mask -band 32) { $words+='Выполнение / проход по каталогу' }
    if ($Mask -band 65536 -or $Mask -band 64) { $words+='Использование права удаления' }
    if ($Mask -band 136) { $words+='Чтение атрибутов' }
    if ($Mask -band 272) { $words+='Запись атрибутов' }
    if (!$words.Count) { return ('Доступ 0x{0:X}' -f $Mask) }
    $words -join ', '
}
# Для файлового события учитываем путь и время подключения: после извлечения букву диска может получить другой СНИ.
function Find-Session([string]$Path, [datetime]$Date) {
    $normalized=$Path
    if ($normalized.StartsWith('\??\')) { $normalized='\\?\' + $normalized.Substring(4) }
    if ($normalized -match '^\\\\\?\\[A-Z]:') { $normalized=$normalized.Substring(4) }
    $best=$null
    $length=-1
    foreach ($s in $state.sessions) {
        if ($Date -lt (Get-Instant $s.start) -or ($s.end -and $Date -ge (Get-Instant $s.end))) { continue }
        foreach ($b in $s.bindings) {
            $name=$b.path
            if ($name.Length -lt $length -or ($normalized -ne $name -and
                !$normalized.StartsWith($name+'\',[StringComparison]::OrdinalIgnoreCase))) { continue }
            if ($Date -lt (Get-Instant $b.start) -or ($b.end -and $Date -ge (Get-Instant $b.end))) { continue }
            if ($name.Length -eq $length -and (!$best -or $best.session -ne $s.session)) { $best=$null }
            else { $best=$s; $length=$name.Length }
        }
    }
    return $best
}
# Читаем события Windows после сохранённой позиции. В запись файла переносим процесс, пользователя и использованные права.
function Import-SecurityEvents([datetime]$Through) {
    $script:backlog=$false
    $bound=Get-UtcText $Through
    if ($state.cursor -lt 0) {
        # Если при запуске журнал был пуст или временно недоступен, учитываем и его первое событие.
        $baseline=$bound
        if ($state.baselineSince -and (Get-Instant $state.baselineSince) -lt $Through) { $baseline=$state.baselineSince }
        $initial=Get-LogAnchor "*[System[TimeCreated[@SystemTime < '$baseline']]]" $true
        $state.cursor=0L
        $state.cursorTime=$null
        if ($initial) { $state.cursor=$initial.id; $state.cursorTime=$initial.time }
    }
    $latest=Get-LogAnchor "*[System[TimeCreated[@SystemTime <= '$bound']]]" $true
    if (!$latest) { return }
    # После очистки Security номер записи может повториться. Сверяем также сохранённое время.
    $anchor=$null
    if ($state.cursor -gt 0) { $anchor=Get-LogAnchor "*[System[EventRecordID=$($state.cursor)]]" $false }
    if ($state.cursor -gt 0 -and (!$anchor -or $anchor.time -ne $state.cursorTime)) {
        $oldest=Get-LogAnchor '*' $false
        if (!$oldest) { return }
        if ($oldest.id -gt $latest.id) { return }
        $state.cursor=[long]$oldest.id-1
        $state.logEpoch=[guid]::NewGuid().ToString()
        $script:transferEvents.Clear()
        $state.transferGapUntil=''
        Add-Notice 'retention' 'Изменился или был перезаписан журнал «Безопасность». Сбор продолжен с доступных записей.'
    }
    if ($state.cursor -ge $latest.id) { Complete-TransferObservations $Through; return }
    $range="(EventRecordID > $($state.cursor)) and (EventRecordID <= $($latest.id))"
    $query="*[System[((EventID=4663 and Task=12812) or ((EventID=4656 or EventID=4663) and Task=12800) or EventID=6416) and $range]]"
    $reader=New-SecurityReader $query $false
    $unmapped=0
    try {
        for ($i=0; $i -lt 256; $i++) {
            $record=$reader.ReadEvent()
            if (!$record) {
                $state.cursor=$latest.id
                $state.cursorTime=$latest.time
                break
            }
            try {
                $xml=[xml]$record.ToXml()
                $fields=@{}
                foreach ($node in $xml.Event.EventData.Data) { $fields[$node.Name]=[string]$node.'#text' }
                $date=$record.TimeCreated.ToUniversalTime()
                if ($record.Id -eq 6416) {
                    # Если носитель извлекли до обнаружения его томов, фиксируем распознавание Windows.
                    # Серийный номер и связь с файловыми операциями указываем только по данным СНИ.
                    $id=[string]$fields.DeviceId
                    if ($id -like 'USBSTOR\*' -or ([string]$fields.ClassId -eq '{4d36e967-e325-11ce-bfc1-08002be10318}' -and [UsbAuditNative]::IsUsb($id))) {
                        $known=@($state.sessions | Where-Object { $_.deviceId -eq $id -and
                            (Get-Instant $_.start) -le $date.AddSeconds(15) -and
                            (!$_.end -or (Get-Instant $_.end) -ge $date) })
                        if (!$known.Count) {
                            New-Entry 'status' $date @{kind='recognition';deviceId=$id;serial=$null;model=$fields.DeviceDescription
                                message="Windows распознала USB-диск $id. Достоверный сеанс и серийный номер на момент события не установлены."
                                recordId=[long]$record.RecordId;logEpoch=$state.logEpoch}
                        }
                    }
                } elseif ([int]$record.Task -eq 12800) {
                    $denied=([long]$record.Keywords -band 0x0010000000000000L) -ne 0
                    $archive=ConvertFrom-ArchiveSecurityEvent -EventId $record.Id -Fields $fields -Denied $denied -ArchiveDirectory (Join-Path $root 'Data\Archive')
                    if ($archive) {
                        $archive.recordId=[long]$record.RecordId
                        $archive.logEpoch=$state.logEpoch
                        New-Entry 'archiveAudit' $date $archive
                    } elseif (!$denied -and $record.Id -eq 4663 -and $fields.ObjectType -eq 'File' -and
                              $script:transferFolders.Count -and ([convert]::ToUInt32($fields.AccessMask,16) -band 6)) {
                        $destination=ConvertTo-TransferDestination $fields.ObjectName
                        if ($destination -and (Test-TransferSessionNear $date) -and !(Find-Session $destination $date)) {
                            Add-TransferObservation 'write' $destination $fields $null $date $record.RecordId
                        }
                    }
                } else {
                    $match=Find-Session $fields.ObjectName $date
                    if ($match) {
                        $mask=[convert]::ToUInt32($fields.AccessMask,16)
                        $account=$fields.SubjectUserName
                        if ($fields.SubjectDomainName) { $account=$fields.SubjectDomainName+'\'+$account }

                                if ($sourcePath -notin @($match.bindings | ForEach-Object { $_.path })) {
                                    Add-TransferObservation 'read' $sourcePath $fields $match $date $record.RecordId
                                }
                            }
                        }
                    } else { $unmapped++ }
                }
                $state.cursor=[long]$record.RecordId
                $state.cursorTime=Get-UtcText $date
            } finally { $record.Dispose() }
        }
    } finally { $reader.Dispose() }
    if ($state.cursor -lt $latest.id) {
        $script:backlog=$true

        }
    } else { Complete-TransferObservations $Through }
    if ($unmapped) {

    }
}

function Get-UsbDestinationPath([string]$Path) {
    if ($Path -notmatch '^[a-zA-Z]:\\' -or $Path.Substring(2).Contains(':')) { throw "Требуется локальный путь к папке NTFS: $Path" }

function Set-UsbDestinationAudit([string]$AppDirectory,[string[]]$Paths) {
    $config = Read-UsbDestinationSettings $AppDirectory

    if (!$Paths -and !@($config.folders).Count) { $Paths = @($inbox) }

        $letter = $path.Substring(0,1)
        if (!$checkedDrives.ContainsKey($letter)) {
            # Внешний USB SSD иногда сообщает тип Fixed. Проверяем также шину физического диска.
            $disks = @(Get-Partition -DriveLetter $letter -ErrorAction Stop | Get-Disk -ErrorAction Stop)
            if (!$disks.Count -or @($disks | Where-Object { $_.BusType -eq 'USB' }).Count) {
                throw "Для папки назначения требуется локальный диск компьютера: $path"
            }
            $checkedDrives[$letter] = $true
        }
        foreach ($ancestor in $requested) {
            if ($path.StartsWith($ancestor+'\',[StringComparison]::OrdinalIgnoreCase)) { throw "Папка $path уже входит в $ancestor. Укажите только родительскую папку." }
        }
        if (![IO.Directory]::Exists($path) -and $path -ine $inbox) { throw "Папка назначения отсутствует: $path" }
    }
    foreach ($path in $requested) {
        if (![IO.Directory]::Exists($path)) { [void][IO.Directory]::CreateDirectory($path) }
        Assert-RegularPath $path
        $sec = [IO.Directory]::GetAccessControl($path,[Security.AccessControl.AccessControlSections]::Audit)
        $before = Get-UsbAuditDescriptor $sec
        $entry = $config.folders | Where-Object { $_.path -ieq $path } | Select-Object -First 1
        if ($entry -and $entry.after -eq $before) { continue }
        if ($entry -and $entry.before -ne $before) { throw "Параметры аудита папки изменились после установки: $path. Сверьте её SACL перед обновлением." }
        $rule = [Security.AccessControl.FileSystemAuditRule]::new([Security.Principal.SecurityIdentifier]::new('S-1-1-0'),[Security.AccessControl.FileSystemRights]6,'ContainerInherit, ObjectInherit','InheritOnly','Success')
        $sec.AddAuditRule($rule)
        $after = Get-UsbAuditDescriptor $sec
        if (!$entry) {
            $entry = [pscustomobject]@{path=$path; before=$before; after=$after}
            $config.folders = @($config.folders) + @($entry)
        }
        # Сохраняем исходное состояние до записи SACL, чтобы прерванную установку можно было повторить.
        Save-UsbDestinationSettings $AppDirectory $config
        if ($after -ne $before) {
            [IO.Directory]::SetAccessControl($path,$sec)
            $actual = Get-UsbAuditDescriptor ([IO.Directory]::GetAccessControl($path,[Security.AccessControl.AccessControlSections]::Audit))
            $entry.after = $actual
            Save-UsbDestinationSettings $AppDirectory $config
        }
    }
}
function Remove-UsbDestinationAudit([string]$AppDirectory) {
    $file = Join-Path $AppDirectory 'destinations.json'
    if (![IO.File]::Exists($file)) { return }
    $config = Read-UsbDestinationSettings $AppDirectory
    foreach ($entry in @($config.folders)) {
        $path = Get-UsbDestinationPath $entry.path
        if ([IO.Directory]::Exists($path) -and $entry.before -ne $entry.after) {
            $sec = [IO.Directory]::GetAccessControl($path,[Security.AccessControl.AccessControlSections]::Audit)
            $current = Get-UsbAuditDescriptor $sec
            if ($current -eq $entry.after) {
                $sec.SetSecurityDescriptorSddlForm($entry.before,[Security.AccessControl.AccessControlSections]::Audit)
                [IO.Directory]::SetAccessControl($path,$sec)
            } elseif ($current -ne $entry.before) { throw "В папке изменился аудит: $path. Сверьте текущую SACL с destinations.json." }
        }
        $config.folders = @($config.folders | Where-Object { $_.path -ine $path })
        Save-UsbDestinationSettings $AppDirectory $config
    }
    [IO.File]::Delete($file)
}

public static class UsbAuditFileComparison {
    const int MaxBytes = 4 * 1024 * 1024;
    static readonly Queue<long> attempts = new Queue<long>();
    static Task<string> worker;
    [StructLayout(LayoutKind.Sequential)]
    struct FileInfo {
        public uint Attributes;
        public System.Runtime.InteropServices.ComTypes.FILETIME Created, Accessed, Written;
        public uint Volume, SizeHigh, SizeLow, Links, IndexHigh, IndexLow;
    }
    [DllImport("kernel32.dll", SetLastError=true)]
    static extern bool GetFileInformationByHandle(SafeFileHandle file, out FileInfo value);
    [DllImport("kernel32.dll", CharSet=CharSet.Unicode)]
    static extern uint GetFinalPathNameByHandle(SafeFileHandle file, StringBuilder name, uint size, uint flags);

    // Не хешируем объекты за точками повторной обработки, временные облачные файлы и тома по UNC.
    static bool OrdinaryPath(string path) {
        if (String.IsNullOrEmpty(path) || path.Length < 4 || path[1]!=':' || path[2]!='\\'
            || path.IndexOf(':',2)>=0 || !String.Equals(Path.GetFullPath(path),path,StringComparison.OrdinalIgnoreCase)) return false;
        for (string item=path; item!=null; item=Path.GetDirectoryName(item)) {
            if (((uint)File.GetAttributes(item) & (0x400u | 0x1000u | 0x40000u | 0x400000u)) != 0) return false;
        }
        return true;
    }
    static bool Inspect(FileStream stream, string expected, out FileInfo info) {
        if (!GetFileInformationByHandle(stream.SafeFileHandle, out info) || (info.Attributes & 0x410u)!=0) return false;
        var name=new StringBuilder(32768);
        uint count=GetFinalPathNameByHandle(stream.SafeFileHandle,name,(uint)name.Capacity,0);
        return count>0 && count<name.Capacity && String.Equals(name.ToString(),@"\\?\"+expected,StringComparison.OrdinalIgnoreCase);
    }
    static bool Stable(FileStream stream, FileInfo before) {
        FileInfo after;
        return GetFileInformationByHandle(stream.SafeFileHandle,out after) && before.SizeHigh==after.SizeHigh
            && before.SizeLow==after.SizeLow && before.Written.dwHighDateTime==after.Written.dwHighDateTime
            && before.Written.dwLowDateTime==after.Written.dwLowDateTime;
    }
    static string Digest(FileStream stream, uint size, Stopwatch clock) {
        var buffer=new byte[64*1024];
        using (var hash=SHA256.Create()) {
            uint total=0;
            while(total<size) {
                if(clock.ElapsedMilliseconds>700) return null;
                int n=stream.Read(buffer,0,(int)Math.Min((uint)buffer.Length,size-total));
                if(n==0) return null;
                hash.TransformBlock(buffer,0,n,buffer,0);
                total+=(uint)n;
            }
            hash.TransformFinalBlock(buffer,0,0);
            return BitConverter.ToString(hash.Hash).Replace("-","").ToLowerInvariant();
        }
    }
    static bool SourceVolumeMatches(FileStream stream,string expected) {
        if(String.IsNullOrEmpty(expected)) return false;
        var actual=new StringBuilder(32768);
        uint flags=expected.StartsWith(@"\\?\Volume{",StringComparison.OrdinalIgnoreCase) ? 1u : 2u;
        uint n=GetFinalPathNameByHandle(stream.SafeFileHandle,actual,(uint)actual.Capacity,flags);
        return n>0 && n<actual.Capacity && String.Equals(actual.ToString(),expected,StringComparison.OrdinalIgnoreCase);
    }
    static string Compare(string from,string to,string expected,Stopwatch clock) {
        try {
            if (clock.ElapsedMilliseconds>150 || !OrdinaryPath(from) || !OrdinaryPath(to)) return null;
            const FileShare share=FileShare.ReadWrite|FileShare.Delete;
            using(var a=new FileStream(from,FileMode.Open,FileAccess.Read,share))
            using(var b=new FileStream(to,FileMode.Open,FileAccess.Read,share)) {
                FileInfo left,right;
                // Буква может перейти другому диску между опросом и открытием файла.
                if(!SourceVolumeMatches(a,expected) || !Inspect(a,from,out left) || !Inspect(b,to,out right)) return null;
                if(left.Volume==right.Volume && left.IndexHigh==right.IndexHigh && left.IndexLow==right.IndexLow) return null;
                long length=((long)left.SizeHigh<<32) | left.SizeLow;
                long targetLength=((long)right.SizeHigh<<32) | right.SizeLow;
                if(length!=targetLength || length==0 || length>MaxBytes)
                    return String.Format(System.Globalization.CultureInfo.InvariantCulture,"sizes:{0}:{1}",length,targetLength);

                return h1==h2 ? h1 : "different";
            }
        } catch (Exception) { return null; }

    public static string TryCompare(string from,string to,string expected) {
        lock (attempts) {
            long now=Stopwatch.GetTimestamp(), minute=60*Stopwatch.Frequency;
            while(attempts.Count>0 && now-attempts.Peek()>minute) attempts.Dequeue();
            if ((worker!=null && !worker.IsCompleted) || attempts.Count>=8) return null;
            attempts.Enqueue(now);
            var clock=Stopwatch.StartNew();
            worker=Task.Factory.StartNew(() => Compare(from,to,expected,clock), System.Threading.CancellationToken.None,
                                        TaskCreationOptions.None, TaskScheduler.Default);
            return worker.Wait(150) ? worker.Result : null;
        }
    }

function ConvertTo-TransferDestination([string]$Path) {
    if ($Path.StartsWith('\??\') -or $Path.StartsWith('\\?\')) { $Path=$Path.Substring(4) }
    foreach ($folder in $script:transferFolders) {
        foreach ($prefix in @($folder.dos,$folder.nt)) {
            if ($prefix -and $Path.StartsWith($prefix+'\',[StringComparison]::OrdinalIgnoreCase)) {
                $rest=$Path.Substring($prefix.Length)
                if ($rest.EndsWith('\') -or $rest.Contains(':') -or $rest -match '(^|\\)\.{1,2}(\\|$)') { return }
                return $folder.dos+$rest
            }
        }
    }
}

function ConvertTo-TransferSource([string]$Path,$Session,[datetime]$When) {
    if ($Path.StartsWith('\??\') -or $Path.StartsWith('\\?\')) {
        $trimmed=$Path.Substring(4)
        if ($trimmed -match '^[A-Z]:\\') { $Path=$trimmed }
    }
    foreach ($volume in $Session.volumes) {
        if (!$volume.letter) { continue }
        foreach ($alias in $volume.paths) {
            $prefix=$alias.TrimEnd('\')+'\'
            if ($Path.StartsWith($prefix,[StringComparison]::OrdinalIgnoreCase)) {
                $dos=$volume.letter+'\'+$Path.Substring($prefix.Length)
                $owner=Find-Session $dos $When
                if ($owner -and $owner.session -eq $Session.session) { return $dos }
            }
        }
    }
    return $Path
}

function Get-TransferVolumePath([string]$Path,$Session) {
    if ($Path -notmatch '^[A-Z]:\\') { return }
    foreach ($volume in $Session.volumes) {
        if ($volume.letter -ne $Path.Substring(0,2)) { continue }
        $nt=$null
        foreach ($alias in $volume.paths) {
            if ($alias.StartsWith('\\?\Volume{',[StringComparison]::OrdinalIgnoreCase)) { return $alias.TrimEnd('\')+$Path.Substring(2) }
            if ($alias.StartsWith('\Device\HarddiskVolume',[StringComparison]::OrdinalIgnoreCase)) { $nt=$alias }
        }
        if ($nt) { return $nt.TrimEnd('\')+$Path.Substring(2) }
    }
}

function Update-TransferWatchers([bool]$Connected,[datetime]$Now) {
    foreach ($folder in $script:transferFolders) {
        $path=$folder.dos
        $watch=$script:folderWatches[$path]
        if (!$watch -and $Connected -and (!$script:watchRetry[$path] -or $script:watchRetry[$path] -le $Now)) {
            try {
                $watch=[UsbAuditDestinationWatcher]::new($path)
                $script:folderWatches[$path]=$watch
            } catch {
                Add-Notice ('watch-open-'+$path) ("Наблюдение папки «"+$path+"» недоступно: "+$_.Exception.GetBaseException().Message)
                $script:watchRetry[$path]=$Now.AddSeconds(30)
            }
        }
        if (!$watch) { continue }
        if ($watch.Error) {
            Add-Notice ('watch-loss-'+$path) ("Перерыв наблюдения за папкой «"+$path+"»: "+$watch.Error)
            $script:watchRetry[$path]=$Now.AddSeconds(5)
        } else {
            foreach ($notice in $watch.Drain()) {
                $destination=ConvertTo-TransferDestination $notice.Path
                if (!$destination) { continue }
                $when=[datetime]::new($notice.Ticks,[DateTimeKind]::Utc)
                if (Test-TransferSessionNear $when) {
                    Test-TransferCapacity $when
                    $script:transferEvents.Add([pscustomobject]@{kind='watch';path=$destination;folder=$path;change=$notice.Change;
                        key='watch|'+[IO.Path]::GetFileName($destination);ticks=$notice.Ticks;rid=('watch-'+[guid]::NewGuid())})
                    $script:transferWatchDirty=$true
                }
            }
        }
        if (!$Connected -or $watch.Error) {
            $watch.Dispose()
            $script:folderWatches.Remove($path)
        }
    }
}

    }

function Complete-TransferObservations([datetime]$Watermark) {
    if (!$script:transferEvents.Count) { return }
    $window=[timespan]::FromSeconds($script:transferWindow).Ticks
    $cutoff=$Watermark.Ticks-$window
    $gap=0L
    if ($state.transferGapUntil) { $gap=(Get-Instant $state.transferGapUntil).Ticks }
    # Обе стороны могут появиться в Security в любом порядке. Решение принимаем после всего окна.
    $groups=@{}
    foreach ($edge in $script:transferEvents) {
        if (!$groups.ContainsKey($edge.key)) { $groups[$edge.key]=[Collections.Generic.List[object]]::new() }
        $groups[$edge.key].Add($edge)
    }
    foreach ($edge in $script:transferEvents) {
        if ($edge.kind -ne 'write' -or $edge.ticks -gt $cutoff) { continue }
        $edge.kind='done'
        if ($edge.ticks -le $gap) { continue }
        $candidates=@{}
        $repeat=$false
        foreach ($other in $groups[$edge.key]) {
            if ($other.rid -eq $edge.rid -or [math]::Abs([long]$other.ticks-[long]$edge.ticks) -gt $window) { continue }
            if ($other.kind -eq 'done' -and $other.path -eq $edge.path -and
                [math]::Abs([long]$other.ticks-[long]$edge.ticks) -le [timespan]::TicksPerSecond*2) { $repeat=$true }
            if ($other.kind -eq 'read') { $candidates[$other.identity.session+'|'+$other.path]=$other }
        }
        if ($repeat -or $candidates.Count -ne 1) { continue }
        $read=@($candidates.Values)[0]
        $when=[datetime]::new([long]$edge.ticks,[DateTimeKind]::Utc)
        $fields=New-TransferFields $read $edge 'pairedAccess'
        $fields.destinationRecordId=$edge.rid
        $digest=Get-TransferDigest $read $edge.path $when
        if ($digest -eq 'different') { continue }
        if ($digest -match '^sizes:(\d+):(\d+)$') {
            if ($Matches[1] -ne $Matches[2]) { continue }
            $fields.sourceBytes=[long]$Matches[1]; $fields.destinationBytes=[long]$Matches[2]
        } elseif ($digest) { $fields.evidence='matchingContent'; $fields.sha256=$digest }
        New-Entry 'transfer' $when $fields
        $edge | Add-Member NoteProperty published $true
    }
    # Для уведомления о новом имени Windows не сообщает процесс записи. Даём парам 4663 приоритет.
    $byName=@{}
    foreach ($item in $script:transferEvents) {
        $name=[IO.Path]::GetFileName($item.path)
        if (!$byName.ContainsKey($name)) { $byName[$name]=[Collections.Generic.List[object]]::new() }
        $byName[$name].Add($item)
    }
    foreach ($edge in $script:transferEvents) {
        if ($edge.kind -ne 'watch' -or $edge.ticks -gt $cutoff-$window) { continue }
        $peers=$byName[[IO.Path]::GetFileName($edge.path)]
        $edge.kind='watchDone'
        if ($edge.ticks -le $gap) { continue }
        $candidates=@{}
        $otherWrite=$false
        foreach ($item in $peers) {
            if ([math]::Abs([long]$item.ticks-[long]$edge.ticks) -gt $window) {continue}
            if ($item.path -eq $edge.path -and $item.published) {$otherWrite=$true}
            if ($item.kind -eq 'read') {$candidates[$item.identity.session+'|'+$item.key+'|'+$item.path]=$item}
        }
        if ($otherWrite -or $candidates.Count -ne 1) {continue}
        $read=@($candidates.Values)[0]
        $when=[datetime]::new([long]$edge.ticks,[DateTimeKind]::Utc)
        $digest=Get-TransferDigest $read $edge.path $when
        if ($digest -eq 'different') {continue}
        $fields=New-TransferFields $read $edge 'observedCreation'
        if ($digest -match '^sizes:(\d+):(\d+)$') {
            $fields.sourceBytes=[long]$Matches[1]; $fields.destinationBytes=[long]$Matches[2]
        } elseif ($digest) {
            $fields.evidence='observedMatchingContent'
            $fields.sha256=$digest
        } else {
            Add-Notice ('watch-verify-'+$edge.folder) ("Содержимое файла для папки «"+$edge.folder+"» проверить не удалось. Возможны ограничения доступа, размера, времени сверки или отключение СНИ.")
        }
        $fields.destinationChange=$edge.change
        New-Entry 'transfer' $when $fields
        $edge | Add-Member NoteProperty published $true
    }
    # Чтение должно пережить ещё одно окно для записей, ожидающих уточнения.
    $keepAfter=$cutoff-2*$window
    $script:transferEvents.RemoveAll([Predicate[object]]{param($edge) $edge.ticks -lt $keepAfter}) | Out-Null
}

# служба и программа обслуживания; чтение отчёта не создаёт новых строк аудита архива.
function Get-ArchiveAuditRoots([string]$ArchiveDirectory) {
    $full = [IO.Path]::GetFullPath($ArchiveDirectory).TrimEnd('\')
    $roots = @($full)
    if ('UsbAuditNative' -as [type]) {
        # Security может записать букву, имя тома с GUID либо собственное имя устройства NT.
        $mount = [IO.DirectoryInfo]::new($full)
        while ($mount) {
            $prefix = $mount.FullName.TrimEnd('\') + '\'
            $volume = [UsbAuditNative]::VolumeName($prefix)
            if ($volume) {
                $suffix = $full.Substring($prefix.Length - 1)
                $volumeName = $volume.Substring(4).TrimEnd('\')
                $nt = [UsbAuditNative]::NtName($volumeName)
                $roots += $volume.TrimEnd('\') + $suffix
                if ($nt) { $roots += $nt.TrimEnd('\') + $suffix }
                break
            }
            $mount = $mount.Parent
        }
    }
    return $roots
}

function ConvertFrom-ArchiveSecurityEvent([int]$EventId,$Fields,[bool]$Denied,[string]$ArchiveDirectory) {
    if ($EventId -notin 4656,4663 -or $Fields.ObjectType -ne 'File') { return }
    $path = [string]$Fields.ObjectName
    if (!$path) { return }
    if ($path.StartsWith('\??\')) { $path = '\\?\' + $path.Substring(4) }
    if ($path -match '^\\\\\?\\[a-zA-Z]:\\') { $path = $path.Substring(4) }
    if ($script:archiveScopePath -ne $ArchiveDirectory -or !$script:archiveScopeRoots) {
        $script:archiveScopeRoots = @(Get-ArchiveAuditRoots $ArchiveDirectory)
        $script:archiveScopePath = $ArchiveDirectory
    }
    $relative = $null
    foreach ($prefix in $script:archiveScopeRoots) {
        if ($path.TrimEnd('\') -ieq $prefix) { $relative = ''; break }
        if ($path.StartsWith(($prefix+'\'),[StringComparison]::OrdinalIgnoreCase)) {
            $relative = $path.Substring($prefix.Length+1)
            break
        }
    }
    if ($null -eq $relative -or $relative -match '(^|\\)\.\.?($|\\)') { return }
    if ([string]$Fields.AccessMask -notmatch '\A0x([0-9a-fA-F]{1,8})\z') { return }
    $mask = [convert]::ToUInt32($Matches[1],16)
    $actions = @(
        if ($mask -band 0x10000) { 'Удаление или переименование' }
        if ($mask -band 0x40) { 'Удаление из каталога' }
        if ($mask -band 6) { if ($relative) { 'Запись данных' } else { 'Создание в каталоге' } }
        if ($mask -band 0x110) { 'Изменение атрибутов' }
        if ($mask -band 0xc0000) { 'Изменение разрешений или владельца' }
    )
    if (!$actions.Count) { return }
    # 4656 описывает запрос дескриптора, 4663 — использование права; завершение удаления
    # по одному праву DELETE не доказано (оно нужно и при переименовании).
    $result = if ($Denied) { 'Отказано в доступе' }
              elseif ($EventId -eq 4656) { 'Доступ запрошен и разрешён' }
              else { 'Право доступа использовано' }
    $account = [string]$Fields.SubjectUserName
    if ($Fields.SubjectDomainName) { $account = $Fields.SubjectDomainName + '\' + $account }
    $name = if ($relative) { $relative } else { '(каталог архивов)' }
    return @{archive=$name; path=$path; action=($actions -join ', '); result=$result; account=$account
        actorSid=[string]$Fields.SubjectUserSid; process=[string]$Fields.ProcessName; source='Windows Security'
        eventId=$EventId; accessMask=[string]$Fields.AccessMask}
}

function Test-ArchiveAuditRule($Security,[bool]$Directory) {

# Разбираем только записи прежнего формата о конце сеанса. Они не указывают причину завершения.
function Read-LegacyEnds([string]$Text, $Sessions) {
    if ($Text.IndexOf('end_unknown',[StringComparison]::Ordinal) -lt 0) { return }
    foreach ($line in $Text.Split([char]10)) {
        if ($line -notmatch '"type"\s*:\s*"end_unknown"') { continue }
        try {
            $row = $line.TrimStart([char]0xfeff) | ConvertFrom-Json -ErrorAction Stop
            if ($row.type -cne 'end_unknown' -or $row.PSObject.Properties['endSource'] -or
                !$row.session -or !$row.deviceId -or !$row.time) { continue }
            $when = if ($row.time -is [datetime]) { $row.time.ToUniversalTime() } else {
                [datetimeoffset]::Parse($row.time,[Globalization.CultureInfo]::InvariantCulture).UtcDateTime
            }
            if ($Sessions.ContainsKey($row.session)) {
                $old = $Sessions[$row.session]
                if ($old -and ($old.lastSeen -ne $when -or $old.deviceId -ine $row.deviceId)) {
                    $Sessions[$row.session] = $null
                }
            } else {
                $Sessions[$row.session] = [pscustomobject]@{session=$row.session; deviceId=$row.deviceId; lastSeen=$when}
            }
        } catch { continue }
    }
}

# Находим события за короткий интервал в отсортированных отметках одного экземпляра устройства.
function Get-TimesInRange($Times, [datetime]$From, [datetime]$To) {
    if ($null -eq $Times) { return }
    $i = $Times.BinarySearch($From)
    if ($i -lt 0) { $i = -bnot $i }
    else { while ($i -gt 0 -and $Times[$i-1] -eq $From) { $i-- } }
    while ($i -lt $Times.Count -and $Times[$i] -le $To) { $Times[$i]; $i++ }
}

function Get-RemovalEvidence($Sessions, [datetime]$AsOf) {
    $ends = @($Sessions.Values | Where-Object { $_ -and $_.lastSeen -le $AsOf } | Sort-Object lastSeen)
    if (!$ends.Count) { return }
    $times = @{}; $volumes = @{}; $parents = @{}
    foreach ($e in $ends) {
        $disk = $e.deviceId
        if (!$times.ContainsKey($disk)) {
            $times[$disk] = [Collections.Generic.List[datetime]]::new()
            $volume = 'STORAGE\Volume\_??_' + $disk.Replace('\','#')
            $volumes[$volume] = $true
            $times[$volume] = [Collections.Generic.List[datetime]]::new()
        }
    }
    # Для дисков USBSTOR Windows нередко записывает отдельно физический USB-родитель и том диска.
    # Связываем их по полному InstanceId из PnP, затем проверяем время обеих записей.
    try {
        $disks = @($ends.deviceId | Sort-Object -Unique)
        foreach ($p in @(Get-PnpDeviceProperty -InstanceId $disks -KeyName DEVPKEY_Device_Parent -ErrorAction SilentlyContinue)) {
            if (!$p -or !$times.ContainsKey([string]$p.InstanceId) -or $p.Data -notmatch '^USB\\VID_[^\\]+\\[^\\]+$') { continue }
            $parents[$p.InstanceId] = $p.Data
            if (!$times.ContainsKey($p.Data)) { $times[$p.Data] = [Collections.Generic.List[datetime]]::new() }
        }
    } catch { } # При недоступной связи PnP по-прежнему учитываем прямое событие диска.
    $upper = $ends[-1].lastSeen.AddSeconds(8)
    if ($upper -gt $AsOf) { $upper = $AsOf }
    $filter = @{LogName='Microsoft-Windows-Kernel-PnP/Device Management'; ProviderName='Microsoft-Windows-Kernel-PnP'
        Id=1010; StartTime=$ends[0].lastSeen.ToLocalTime(); EndTime=$upper.ToLocalTime()}
    $guid = '[0-9a-f]{8}-(?:[0-9a-f]{4}-){3}[0-9a-f]{12}'
    Get-WinEvent -FilterHashtable $filter -ErrorAction Stop | ForEach-Object {
        $event = $_
        try {
            $xml = [xml]$event.ToXml()
            $field = $xml.Event.EventData.Data | Where-Object { $_.Name -eq 'DeviceInstanceId' } | Select-Object -First 1
            $id = if ($field) { [string]$field.'#text' }
            if ($id -and $id -match "^(.+)#\{($guid)\}$" -and $volumes.ContainsKey($Matches[1])) {
                $id = $Matches[1]
            } elseif ($id -and $volumes.ContainsKey($id)) {
                $id = $null
            }
            if ($id -and $times.ContainsKey($id)) {
                $times[$id].Add($event.TimeCreated.ToUniversalTime())
            }
        } finally { $event.Dispose() }
    }
    foreach ($list in $times.Values) { $list.Sort() }
    foreach ($e in $ends) {
        $from = $e.lastSeen; $to = $from.AddSeconds(8)
        $disk = $e.deviceId
        $direct = @(Get-TimesInRange $times[$disk] $from $to)
        $paired = @()
        if ($parents.ContainsKey($disk)) {
            $volume = 'STORAGE\Volume\_??_' + $disk.Replace('\','#')
            $volumeTimes = @(Get-TimesInRange $times[$volume] $from $to)
            $paired = @(foreach ($t in (Get-TimesInRange $times[$parents[$disk]] $from $to)) {
                if (@($volumeTimes | Where-Object { [Math]::Abs(($_-$t).TotalSeconds) -le 2 }).Count) { $t }
            })
        }
        if ($direct.Count -gt 1 -or $paired.Count -gt 1 -or
            ($direct.Count -eq 1 -and $paired.Count -eq 1 -and [Math]::Abs(($direct[0]-$paired[0]).TotalSeconds) -gt 2)) { continue }
        $time = if ($direct.Count) { $direct[0] } elseif ($paired.Count) { $paired[0] }
        if ($time) {
            [pscustomobject]@{session=$e.session; deviceId=$disk; lastSeen=$from.ToString('o'); time=$time.ToString('o')}
        }
    }
}

function changeAction(record){

function applyRemovalEvidence(evidence){
    if(!Array.isArray(evidence) || !evidence.length)return;
    const intervals=new Map(), candidates=new Map();
    for(const item of evidence){
        if(!item)continue;

            || seen!==s.end || !Number.isFinite(when) || when<seen || when-seen>8000)continue;
        const id=norm(s.deviceId);
        if(!intervals.has(id))intervals.set(id,{starts:[],ends:[]});
        if(candidates.has(s.key) && candidates.get(s.key)!==when)candidates.set(s.key,null);
        else candidates.set(s.key,when);
    }
    for(const s of sessions.values()){
        const group=intervals.get(norm(s.deviceId));
        if(group){group.starts.push(s.start??-Infinity);group.ends.push(s.end??Infinity)}
    }
    function countThrough(sorted,time){
        let lo=0,hi=sorted.length;
        while(lo<hi){const mid=lo+Math.floor((hi-lo)/2);if(sorted[mid]<=time)lo=mid+1;else hi=mid}
        return lo;
    }
    for(const group of intervals.values()){group.starts.sort((a,b)=>a-b);group.ends.sort((a,b)=>a-b)}
    for(const [key,when] of candidates){
        if(when===null)continue;
        const s=sessions.get(key), group=intervals.get(norm(s.deviceId));
        // Считаем сеансы, пересекающие интервал от последнего наблюдения до события PnP.
        if(countThrough(group.starts,when)-countThrough(group.ends,s.end-1)!==1)continue;
        s.lastSeen=s.end;s.end=when;s.unknown=false;s.endSource='kernelPnp';
    }
}

function Read-Message([string]$Path) {
    # На время чтения запрещаем запись, чтобы разобрать целый запрос.
    $file = [IO.File]::Open($Path,'Open','Read',([IO.FileShare]::Read -bor [IO.FileShare]::Delete))
    try {
        if ($file.Length -eq 0) { return $null }
        if ($file.Length -gt 8192) { throw [IO.InvalidDataException]::new('Служебное сообщение слишком велико.') }
        $reader = [IO.StreamReader]::new($file,$utf8,$true)
        try {
            $raw = $reader.ReadToEnd()
            try { $msg = $raw | ConvertFrom-Json -ErrorAction Stop } catch { throw [IO.InvalidDataException]::new('Повреждено служебное сообщение.') }
            if (!$msg -or $msg -is [array] -or ([string]$msg.id -cnotmatch '^[0-9a-f]{32}$')) {
                throw [IO.InvalidDataException]::new('Повреждён номер служебного запроса.')
            }
            return $msg
        } finally { $reader.Dispose() }
    } finally { $file.Dispose() }
}

function Save-Message([string]$Path,$Message,[switch]$Atomic) {
    # SYSTEM атомарно заменяет результат и отметку о начатом удалении.

    for ($i=0; $i -lt 15; $i++) {
        try { $handle = [IO.File]::Open($output,$mode,'Write','None'); break }
        catch [IO.IOException] { if ($i -eq 14) { throw }; Start-Sleep -Milliseconds 100 }
    }

        $handle.SetLength(0)
        $handle.Write($bytes,0,$bytes.Length)

        Save-Message $requestFile @{id=$id;action=$Action;archive=$Archive;actorSid=$Settings.custodianSid;generation=$Settings.requestGeneration}
        $response = Wait-Response $id $jobTask $Settings
        if ($response.status -ne 'ok') { throw $response.message }
        Write-Host $response.message
    } finally { $submit.Dispose() }
}
function Invoke-ArchiveOperation($Settings) {
    $account = Get-CustodianAccount $Settings
    if ($Settings.custodianMode -ceq 'ExistingAdmin') { [void](Get-SelectedLocalAdmin ([string]$Settings.custodianSid)) }
    $name = $account.Substring($account.IndexOf('\') + 1)
    Write-Host "Учётная запись: $account. Операция: $Action $Archive"
    $password = Read-Host "Введите пароль $account" -AsSecureString
    try {
        if (!$password -or !$password.Length) { throw 'Для этой операции требуется пароль.' }
        try { $token = Open-CustodianToken $name $password }
        catch { throw "Windows отклонила вход $account. Проверьте пароль и состояние учётной записи. $($_.Exception.GetBaseException().Message)" }
        try {
            # Сравнение SID защищает и от пересоздания УЗ с таким же именем.
            $verified = [Security.Principal.WindowsIdentity]::new($token.DangerousGetHandle())
            try {
                if ($verified.User.Value -cne [string]$Settings.custodianSid) { throw 'SID учётной записи не совпадает с назначенным.' }
            } finally { $verified.Dispose() }
        } finally { $token.Dispose() }
    } catch {
        Write-ArchiveOperationRecord $operationName $Archive 'Проверка учётной записи отклонена' $operationId 'auth'
        throw
    } finally { if ($password) { $password.Dispose() } }
    Submit-ArchiveRequest $Settings
}
# Rotate и Delete проходят одну и ту же проверку, включая запуск от имени ответственного.
$operationId = [guid]::NewGuid().ToString('N')
$operationName = if ($Action -eq 'Delete') { 'Удаление архива' } else { 'Закрытие журнала' }
# Сохраняем запрос до проверки пароля: даже закрытое на этапе ввода окно оставляет след.
Write-ArchiveOperationRecord $operationName $Archive 'Запрошено в программе' $operationId 'requested'
Invoke-ArchiveOperation $config
} finally {
    foreach ($key in $savedEnvironment.Keys) {
        [Environment]::SetEnvironmentVariable($key,$savedEnvironment[$key])
    }
}

# Для контрольного файла объединяем права доступа только внутри одного сеанса и одного полного пути.
function Test-FileEvidence($Lines, [string]$Name, [datetime]$Since) {
    $rights = @{}
    foreach ($line in $Lines) {
        try {
            $row = $line | ConvertFrom-Json -ErrorAction Stop
            if ($row.type -ne 'file' -or !$row.session -or !$row.deviceId) { continue }
            $instant = if ($row.time -is [datetime]) { $row.time.ToUniversalTime() }
                       else { [DateTimeOffset]::Parse($row.time,[Globalization.CultureInfo]::InvariantCulture).UtcDateTime }
            if ($instant -lt $Since) { continue }
            $path = [string]$row.path
            if ($path -notmatch '\\' -or $path.EndsWith('\') -or [IO.Path]::GetFileName($path) -ne $Name) { continue }
            if ($path -match '^\\Device\\HarddiskVolume\d+$' -or $path -match '^\\\\\?\\Volume\{[^}]+\}$') { continue }
            if ($row.accessMask -notmatch '^0x([A-Fa-f0-9]{1,8})$') { continue }
            $mask = [Convert]::ToUInt32($Matches[1],16)
            $key = $row.session + '|' + $path
            $rights[$key] = [long]$rights[$key] -bor [long]$mask
            if (($rights[$key] -band 1) -and ($rights[$key] -band 6)) { return $true }
        } catch { continue }
    }
    return $false
}
